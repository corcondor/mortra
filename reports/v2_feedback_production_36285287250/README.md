# V2制作ループへのオンライン経験接続: 開発比較

**実際の候補評価への接続が成立しました。記録・再計算だけのBはAと同じ制作履歴になりました。未攻略時に探索するCでは制作履歴が変わり、targeted系列の最終成功数は350/400から400/400になりました。ただし共通C評価器では全条件の最終ゲームが攻略できました。**

## 実行と固定条件

- 基準checkout: `90a7bba04ce8895869b6b2eb7b3dd7d8cae25207`。前回結果はそのまま保存されています。
- 実接続確認: [run 36284251256](https://github.com/corcondor/mortra/actions/runs/36284251256)、コード `8aefadc21004cee6842ffb9aac6c09e5e6b62a8b`。
- 本比較: [run 36285287250](https://github.com/corcondor/mortra/actions/runs/36285287250)、コード `8ba2dc57049bfb20f9240975b67dcfe79290b905`。全18ジョブ成功。
- 既知8 seed: 79020000..79020007。新規世界での確認実験ではありません。
- A: 追加経験を利用しない。B: 記録・再計算。C: Bに未攻略時の既存探索を追加。
- targetedは既存の批評に基づく変更、randomは既存の無作為変更です。どちらも変更・採否を既存MORTRA関数が実行しました。
- 各候補で新しい学習器を作り、初期2500操作、追加5000操作、その後に更新を止めた50試行を実行しました。評価上限は100操作です。
- Player、Designer、批評、mutation、採否、q=0.90、source=1、同点処理は変更していません。A/B指定用の薄い別アダプターだけを追加しました。

## 制作比較

8 seed × A/B/C × targeted/random = 48系列を各20反復実行しました。初期評価を含め1008候補評価です。
費用は成功時の実操作数、失敗時100操作です。この表の費用は評価時だけで、学習費用は後述します。

| 制作系列 | 条件 | 最終成功 / 400試行 | 最終平均費用 / 操作 | 採用編集数 / 160提案 | 最終ゴール変更 / 8ゲーム |
|---|---|---:|---:|---:|---:|
| targeted | A | 350 | 27.000 | 23 | 1 |
| targeted | B | 350 | 27.000 | 23 | 1 |
| targeted | C | 400 | 14.125 | 24 | 1 |
| random | A | 400 | 15.250 | 14 | 3 |
| random | B | 400 | 15.250 | 14 | 3 |
| random | C | 400 | 17.875 | 23 | 6 |

A/Bは全16組で最終ゲームが一致しました。候補ゲーム・保持ゲーム・批評・変更内容・採否の履歴も一致しました。
これは今回の条件での観測結果であり、記録処理が一般に無価値であるという結論ではありません。

## 共通評価

制作終了後、最終48ゲームをすべて同じC評価器で初期2500・追加5000操作から再学習しました。
その後、50回の凍結自己プレイと50回の既存ランダム評価を実行しました。この結果は選択へ戻していません。

| 制作系列 | ゲームを作った条件 | 共通C成功 / 400 | 共通C平均費用 / 操作 | ランダム成功 / 400 |
|---|---|---:|---:|---:|
| targeted | A | 400 | 15.500 | 51 |
| targeted | B | 400 | 15.500 | 51 |
| targeted | C | 400 | 14.125 | 25 |
| random | A | 400 | 15.250 | 43 |
| random | B | 400 | 15.250 | 43 |
| random | C | 400 | 17.875 | 16 |

共通Cとランダムの成功率差は、A/Bで作ったゲームと比べて、Cで作ったゲームではtargetedで6.50ポイント、randomで6.75ポイント大きくなりました。
同じゲームへのPlayer比較ではなく、異なる制作過程が作ったゲーム集合の記述的比較です。
評価条件・乱数は共通ですが、新規のランダムseedによる確認ではありません。面白さやゲーム全般の優劣は、この数値だけでは判定しません。

## 指定された差

各値は同じ初期seedで対応させた8ゲームの平均費用差です。正は操作数増加、負は減少です。
最終ゲームが異なるため、操作数増加をそのままPlayerの悪化とは解釈しません。

| 差 | targeted: 各系列自身の評価 | targeted: 共通C評価 | random: 各系列自身 / 共通C |
|---|---:|---:|---:|
| C−B | −12.875 | −1.375 | +2.625 |
| B−A | 0 | 0 | 0 |
| C−A | −12.875 | −1.375 | +2.625 |

共通C費用のC−Bは、targetedで減少2・同値5・増加1ゲーム、randomで減少2・同値1・増加5ゲームです。
中央値と全seedの生の差は[paired_contrasts.json](summary/paired_contrasts.json)に保存しました。400試行を400独立ゲームとは扱いません。

## 同じゲームの攻略とゲーム変更の区別

初期ゲームへのCは、今回も79020003で追加283操作、79020004で追加396操作に初めてゴールを観測しました。
その時点ではゲームもゴールも変えていません。初期ゲーム8個への凍結評価はA/Bが300/400、Cが400/400でした。

その後の制作ではゲーム変更を許可しています。最終ゴールが初期から変わったseedは以下です。

- targeted A/B: 79020003。targeted C: 79020002。
- random A/B: 79020002、79020004、79020007。
- random C: 79020000、79020002、79020003、79020005、79020006、79020007。

ゴールが同じでも壁・開始位置・他の要素が変わる場合があります。
全960提案について、ゲーム変更、ゴール変更、開始位置変更、採否、成績変化を[all_game_changes.csv](summary/all_game_changes.csv)に分離して記録しました。
旧関数の批評文字列にある「unsolvable」は、その評価器での未攻略判定です。真の到達不能性を証明した値として扱っていません。

# 選択問題への忠実度修正レポート（2026-08-02）

## 発生していた問題

異なる問題を選択しても、生成器が `polynomial_roots` のような一般タグだけを根拠に、深さの大きい `irrational_cubic_root_triangle` 族を優先していた。その結果、親問題に三角形が含まれない場合でも、三次方程式の根を三角形の辺とし、外心・内心を問う問題へ収束していた。

探索時間も最大時間としてしか使われず、最初の非重複候補を即採用していた。さらに、1問目で検査した不採用候補までセッション全体の使用済みにしていたため、3問要求しても2問目以降が生成できない場合があった。

## 修正

- 親ごとに固有な構造署名を作り、全親を被覆しない候補を採用しない。
- 融合時は全親を結ぶAtlas中継網だけを使い、単独親や親ペアへの暗黙の後退を禁止する。
- 深さの加点を線形から対数へ変更し、意味一致を深さより優先する。
- 最初の候補を即採用せず、時間予算内で中間仮説を比較して最良候補を選ぶ。
- 不採用候補の重複管理を問題ごとに分離する。
- 親が2問未満の融合要求は開始前に拒否する。
- 誤ルーティングで保存された直近12問を問題DBから削除した。

## 再現試験

親問題:

1. 1のn乗根をMöbius変換して三角関数和を求める問題
2. 交比一定の複素数列をMöbius反復として解析する問題

生成された共通核:

`交比 → Möbius作用 → 回転作用との共役 → 1のn乗根の有限軌道 → 対数微分 → 軌道観測`

30秒設定、3問生成の結果:

| 観測 | 中間仮説 | 実探索 | 検証段 | 全親被覆 |
|---|---:|---:|---:|---|
| 中心化二次モーメント | 265,803 | 8.0秒 | 23 | 成功 |
| 2点積の総和 | 262,844 | 8.0秒 | 23 | 成功 |
| 二次モーメント | 231,658 | 8.0秒 | 23 | 成功 |

生成数は3/3、三角形族への誤ルーティングは0/3だった。90秒設定では、3問全体で約60秒を最低探索時間として使用する。

## 独立検算

MathOS内の複素数直接評価とは別にWolfram Languageで厳密和を計算し、3問とも一致した。

- `36`
- `8005/961`
- `1845493760/17592177655809`

この試験はMöbius・単位根構造に対する修正の実証であり、任意の親問題から常に新しい実行核を発明できることまでは示していない。未接続構造を既存族へ誤配信しないことと、新しい核を追加した後に同じ被覆試験を通すことを今後の受理条件とする。

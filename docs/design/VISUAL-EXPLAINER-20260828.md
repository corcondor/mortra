# 研究記録のビジュアル説明「The Collapse」（2026-08-28）

公開先 https://claude.ai/code/artifact/bfdb448d-3b1f-4d4d-9c43-83f234e30e27
ソース `scratchpad/mortra-representation.html`（このリポジトリ外。再公開は同じパスから）

## 目的

`MORTRA-MINIMAL-REPRESENTATION-CHARTS-20260827.md` の内容を、数学の予備知識がない読者にも
届く形で視覚的に説明する。数学オタク向けの投稿ではなく、**これができると何になるのか**、
**結局何がしたいのか**、**どのビジョンにつながるのか**を伝えることを主目的にした。

## 何を主題にしたか

研究記録の考察にある一文を、ページ全体の背骨にした。

> 探索深度や変換規則数を増やした効果ではない。7問とも、長い構成を別の表現へ移して
> 次元を下げたことが直接の要因である。

したがってページの主題は「85.4%という数字」ではなく、**「見方を変えると閉じる」という動き**
そのものにした。すべての図が同じ形をしている。左に膨れた構成、右に小さな恒等式。

一般化のセクションでは、同じ動きが数学の外にもあることを示した。畳み込み→フーリエ→掛け算、
点も球も変換も→幾何代数→1種類の multivector、4変数の一括展開→MORTRAのチャート→`U+V=E+F`。
この3行を並べることで、MORTRAが「幾何の道具」ではなく**表現を乗り換える機械**であることを、
数式なしで伝えられる。

### `html` スキルとの衝突（未解決）

**制作を終えたあとに気づいたため、今回の成果物には反映できていない。**

（`document.css` 13.4KB、`component-samples.html` 12.2KB、`math-copy.js` 1.8KB）

両者の規定は次のように食い違う。

| 項目 | `html` スキルの規定 | 今回の成果物 |
|---|---|---|
| 背景 | `#FAF9F6` クリーム | `#05070a` 黒 |
| 部品 | 白地・黒罫線・角丸 | 罫線のみ、角丸ほぼなし |
| 有彩色 | 青 `#2990DA` と赤 `#D63A2F` の2色のみ | MORTRAの射5色 |
| 強調 | 赤は1ページ1箇所まで | 緑を崩壊の到達点に反復使用 |
| 図 | 黒一色の線画 | 色付きSVG＋キャンバス |
| 書体 | Ubuntu Sans / Noto Sans JP / Ubuntu Mono | Newsreader / IBM Plex Mono |
| 構成 | 用語リスト→背景→本論→具体例→補足、目次必須 | 主張→数値→実験→一般化→限界 |

**どちらが正しいかは、この文書の用途で決まる。** 判断材料は次のとおり。

- `html` スキルの体裁は、研究記録と並べる**論文形式の資料**に向く。
  数式（MathJax）、用語リスト、目次、出典表記の作法が揃っている。
  一方で、色数と黒線画の制約から、SNSの広告として目を引く力は弱い。
- 今回の成果物は、**サイト本体と同じブランドで、外に見せる**ことを狙っている。
  操作できる崩壊が主役なので、静的な論文形式にすると主題そのものが消える。

**現状は後者で作ってある。** 論文形式が必要なら、同じ内容を `html` スキルの
デザインシステムで作り直せる。その場合、冒頭のキャンバスは黒線画の静止図に置き換わる。

## 設計

### 色

MORTRAの既存の5色をそのまま使い、地と中間色だけを新しく定義した。

```
--ground   #05070a   地。純黒でも純グレーでもなく、青緑へわずかに寄せる
--ground-2 #080c11   図の内側
--rule     #16222c   罫線
--ink      #e8eef2   本文。冷たい白
--dim      #7d919e   副文。青へ寄せた中間色
--dimmer   #4a5a66   最も弱い文字

--construct #ff9d2e  膨れた側・元の表現
--theorem   #ff5fb0
--algebra   #ffffff
--close     #4dffa0  畳まれた側・移した先
--numeric   #4fc3ff  リンク・問題ID
```

**灰色を使わない。** 純グレーは「選んでいない色」に見えるため、中間色はすべて青へ寄せた。
これは指摘された「灰色の背景とか、AIがつくったものって感じ」への直接の対応。

**明暗2テーマを持たない。** 黒地に光る線として証明が起きる、という一点に賭けた。
そのかわり背景も文字色もすべて明示的に塗り、どの地の上に置かれても崩れないようにしてある。

### 書体

```
Newsreader        見出しと論説。可変光学サイズ付きのセリフ
IBM Plex Mono     数値・式・ラベル・問題ID
```

`Inter` と `Space Grotesk` は使わなかった。AI生成ページの既定として指摘されている書体で、
一目でそれと分かるため。セリフを論説に当てることで「研究論文」の語り口を作り、
数値だけをモノスペースに落として、**主張と測定値を書体で分離**した。

サイトの既存は Plex Mono + Plex Sans だが、この成果物は説明のための別の器なので、
論説側だけ Newsreader に替えた。配色はブランドなので変えていない。

### 構成

```
1  ヒーロー      主張1行 ＋ 操作できる崩壊
2  数値          28 / 76 / 13 / 0、そして2つは種類が違うという但し書き
3  介入実験      2011G3 のA/B。3分で終わらない経路と、閉じた経路
4  7つの崩壊     7チャートを「元の構成 → 移した先」の表として
5  一般化        フーリエ・幾何代数・MORTRA が同じ動きであること
6  限界          85.4%は汎化率ではない。量化不一致の2問を数えない理由
7  結び          Finite primitives. Infinite mathematics.
```

**6を省かなかったことが、この資料の性格を決めている。** 研究記録が自ら書いている限界を
そのまま載せた。post-hoc追加であること、未見集合の正答率ではないこと、量化修復なしには
加点しないこと。数字を大きく見せる資料ではなく、**数字の意味を正確にする**資料にした。

### 削除した節（2026-08-28 の指摘による）

初版には AlphaGeometry2 との比較節を置いていた。本人の指示で削除した。指摘は2点。

1. **体裁として良くない。** 他社との比較を並べる構成そのものを外す。
2. **「別集合だから比較しない」という書き方が誤り。** ベンチマークはこれから測るので、
   正しくは「まだ測っていない」であって「比較できない」ではない。
   `lib/mortra/i18n.ts` の方針コメントが
   「『まだ測っていない』ことは、書かないのではなく、書いて明示する」と定めており、
   初版はこの自前の規範に反していた。

出典欄からも内部パス（`lib/mortra/i18n.ts`、凍結名簿のJSON、arXivリンク）を外し、
研究記録へのリンクと `mortra.ai` だけを残した。内部の配管を公開面に出さない。

### 冒頭の崩壊（唯一の賭け）

装飾のアニメーションではなく、`2011G3` の実際の経路を描いている。

```
t=0.00  4変数の一括展開。420個の項が中央から放射状に膨れている
t=0.44  4つの橋へ集まる（直径円上の点／3垂足円／交差する割線／平行四辺形）
t=0.88  1本の帯に畳まれ、項が間引かれていく
t=1.00  U + V = E + F が立ち上がる
```

- 種を `20110303` に固定した線形合同法で配置するので、**毎回同じ絵**になる。
- 色は畳まれる進行度で `--construct` から `--close` へ連続的に移る。
- 読み値は「展開中の項 420 → 恒等式の項 2」と実際に減る。
- 初回のみ自動で一度通しで動き、以降は読者がスライダで前後に動かせる。
  「1段動かす = 1段畳まれる」という、サイト本体と同じ操作の設計。
- `prefers-reduced-motion` では自動再生せず、追従も即座にする。

## 正確さについて

数値はすべて `lib/mortra/i18n.ts` の `FIGURES` と
`docs/research/MORTRA-MINIMAL-REPRESENTATION-CHARTS-20260827.md` から転記した。
このページ内で数字を独自に計算していない。

- `76/89 = 85.4%` 監査済み能力和／`28/89 = 31.5%` 公式Newclid単体／残り13問
- 7チャートの局所恒等式数（15, 22, 22, 20, 18, 30, 23）はすべて実装表から
- 回帰（7/7・36/36・88/88・168/168・誤一致0）は結果表から
- `2011G3` の証明書SHA-256 先頭8桁のみ表示
- AG2は arXiv 2502.03544 と `google-deepmind/alphageometry2` の README から。
  **IMO-AG-50 と IMO-AG-30 は別集合なので率を直接比較していない。**

## 残っている課題

- 実物の目視確認ができていない。ローカルでは描画とスクラブの動作を確認したが、
  公開後のアーティファクトは非公開のためブラウザ側から開けなかった。
  **幅・字組み・崩壊の見え方は、本人の目で一度確認してほしい。**
- 英語版がない。サイト本体は2言語なので、投稿に使うなら英語も要る。
- 動画にしていない。インスタ／Xに出すなら、崩壊の部分を9:16で書き出す工程が別に必要。

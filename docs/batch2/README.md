### S2: 空間平板の床への透視影投影
- **光源**: $L_1 = (-3, -4, 8)$, $L_2 = (3, -4, 8)$
- **平板**: $K = [-1, 1] \times [-1, 1]$（$z = 2$）
- **床面**: $z = 0$
- **投影倍率**: $t = \frac{z_L}{z_L - z_P} = \frac{8}{8 - 2} = \frac{4}{3}$
- **影の頂点**:
  - $L_1$: $(-1/3, 0, 0), (7/3, 0, 0), (7/3, 8/3, 0), (-1/3, 8/3, 0)$ $\implies$ 面積 $\Delta x \Delta y = \frac{8}{3} \times \frac{8}{3} = \frac{64}{9} \approx 7.1111$
  - $L_2$: $(-7/3, 0, 0), (1/3, 0, 0), (1/3, 8/3, 0), (-7/3, 8/3, 0)$ $\implies$ 面積 $\frac{64}{9}$
  - 重複領域（本影 Umbra）: $x \in [-1/3, 1/3], y \in [0, 8/3]$ $\implies$ 面積 $\frac{2}{3} \times \frac{8}{3} = \frac{16}{9} \approx 1.7778$

### W2: 4f 光学空間フィルタリング
- **パラメータ**: 波長 $\lambda = 532$ nm, 焦点距離 $f = 100$ mm, 空間遮断周波数 $\nu_c = 8\,\text{mm}^{-1}$
- **フーリエ面遮断半径**: $r_c = \lambda f \nu_c = 532\times 10^{-9} \times 0.1 \times 8000 = 0.4256\,\text{mm}$
- **接続**: MORTRA `geometry_alphabet` (ROMAN 'M') および `geometry_raster.render` による有理距離モルフォロジー生成文字 + 周期 $40\,\mu\text{m}$ 高周波格子
- **物理正規化**: レンズ2段伝搬による空間反転 $u_{out}(x,y) = -u_{in}(-x,-y)$ および完全電力保存 $P_{all} = P_{in}$（比率 $1.000000$、反転誤差 $8.79 \times 10^{-33}$）
- **結果**:
  - (a) 入力像: 幾何文字 'M' + 高周波格子
  - (b) フーリエスペクトル面に $r_c = 0.4256$ mm のアパーチャを設定
  - (c) 全通過: 厳密な倒立像
  - (d) 低域通過（$r \le r_c$）: 格子成分が遮断され、エッジが滑らかな像を結像（電力比 $68.17\%$）
  - (e) 高域通過（$r > r_c$）: DC成分が遮断され、高周波格子と文字エッジのみが抽出（電力比 $31.83\%$）

![W2 4f Spatial Filtering](./task_w2_4f_spatial_filtering.png)

### W3: 2深度単一位相ホログラム
- **格子**: $256 \times 256$, 画素ピッチ $8\,\mu\text{m}$, $\lambda = 532$ nm
- **目標 1 ($z_1 = 8\,\text{mm}$)**: 二重リング（外径 $0.30$ mm, 内径 $0.20$ mm）
- **目標 2 ($z_2 = 12\,\text{mm}$)**: 塗りつぶし三角形（底辺 $0.6$ mm, 高さ $0.55$ mm）
- **3深度評価**:
  - $z_1 = 8\,\text{mm}$: リング合焦（コントラスト $17.37$, クロストーク $0.5070$）
  - $z_{\text{mid}} = 10\,\text{mm}$: 中間遷移領域（双方デフォーカス）
  - $z_2 = 12\,\text{mm}$: 三角形合焦（コントラスト $19.27$, クロストーク $0.3871$）
  - ※クロストーク $0.507 / 0.387$ は本位相単一面＋現在のWGSで観測された残留クロストークであり、理論的下限を示すものではありません。
- **伝搬一貫性**: `wave_optics_system.TransferFunction` との最大相対差 $8.63 \times 10^{-12}$ で完全一致確認。

### R1: 拡散陰影付き点描球
- **幾何配置**: 球 $x^2 + y^2 + (z-1)^2 = 1$（中心 $(0,0,1)$, 半径 $1$）, 床 $z = 0$

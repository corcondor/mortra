# Rikyū 分解（公開範囲のみ）

2026-08-12 に https://rikyu.ai/ja を通常のブラウザで開いて観察した。
認証の回避・非公開APIの探索・ソースの複製は行っていない。
各項目を **OBSERVED / STRONG INFERENCE / WEAK INFERENCE / UNKNOWN** に分ける。

## 最初の5秒

**OBSERVED**

```
見出し    「もう、デザインしなくていい。」
次の節    「伝えたのは、この一文だけ。」
          「素材を、探さなくていい。」
          「いつものAIを、Rikyūにつなぐ。」
末尾      「デザインしない、デザインツール。」
CTA       無料ではじめる（複数箇所）／ 料金プラン ／ MCP連携
背景      oklch(0.17 0.012 95.66)  暗いが純黒ではない。わずかに暖色
書体      Zen Kaku Gothic New
```

**要点。** 見出しが機能ではなく**やらなくてよくなること**を言っている。
「デザインできます」ではなく「デザインしなくていい」。
これは MORTRA にそのまま効く。「数学が解けます」ではなく
「解法を思いつかなくていい」「図を描かなくていい」の側で書ける。

## 中核のループ

**OBSERVED** トップに実際の依頼文がそのまま置かれている。

```
「アントワープ発のコートブランドを立ち上げたい。」
「コーヒーと音楽でくつろげる店をはじめたい。」
```

**STRONG INFERENCE** 一文の依頼 → 一つの持続する制作状態 → 多数の成果物。
ブランド名（ELIAS VARR / Waypause / LOWBELL）が並んでいるのは、
**一つの依頼から派生した成果物の束**を見せているため。
機能の一覧ではなく、成果物の一貫性を売っている。

**UNKNOWN** 改訂が成果物単位かプロジェクト単位か、履歴があるか、
改訂がどこまで伝播するかは、ログインの内側なので観測できない。

## MCP

**OBSERVED** 「いつものAIを、Rikyūにつなぐ。」というルートが独立してある（`/ja#mcp`）。

**STRONG INFERENCE** 製品UIと、Claude/Codex からの利用を並列の入口として扱っている。
UIを使わせることに固執していない。

## 公開クライアント技術

**OBSERVED**
```
Next.js（/_next/ のスクリプト）
ルート  /ja, /ja#pricing, /ja#mcp, /ja/terms, /ja/privacy, /ja/legal, /ja/cookies
配色    oklch 指定（sRGB ではなく知覚均等な色空間）
```

**WEAK INFERENCE** ロケール接頭辞（`/ja`）があるので多言語前提。

## 数字（別途観測）

「ロゴを幾何学的にデザインしてくれる機能」の投稿は
**96.2万再生 / いいね 9,784 / リポスト 572 / ブックマーク 7,453**。

**ブックマーク／いいね = 0.76** が異常に高い。しかも**静止画4枚**で動画ではない。
勝因は演出ではなく「自分で使いたい」。

## 真似してはいけないもの

- 見た目の複製（配色・書体・レイアウトの写し取り）
- 「〜しなくていい」という言い回しの流用。同じ構文で書くと二番煎じになる
- 暗い背景＋大きい余白だけを真似ること。それは結果であって理由ではない

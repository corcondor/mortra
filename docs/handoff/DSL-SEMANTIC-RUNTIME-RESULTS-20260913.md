fresh Linux comparison, but semantic editing has not improved the number of
solved generalization tasks. It reduces counted mathematical work while its
remaining overhead increases end-to-end time. This is progress, not completion
of the persistent-learning objective.

knowledge. Original definitions and proof/dependency records remain immutable.

**Interpreter B versus U:** exact same solved flags, program bodies, search
states, work and rewrite traces in all four cohorts. Fresh process time falls

12,960,400 key bytes and costs 0.568 seconds; rebuilding costs 2.893 seconds.

start for every task. Uncached zero cache hits/misses mean the cache is bypassed,
not that parsing disappeared. This is an infrastructure result, not capability
acquired by MORTRA.

Of these tasks, **31 have value functions not observed in either training
archive**. A solves 6/31; all learned conditions solve 4/31. Across all 48 there
is one A-unsolved/B-solved task (`918051/external-18`), but its value function
already appeared in training, and L/F/C also solve it. It does not establish a
new semantic-editing capability. Two A-solved tasks are lost in B
(`918051/external-07`, `918052/external-23`). No tasks were selected or removed
after seeing these outcomes.

On the 20 tasks solved by all conditions, B explores 1,656 states versus C's

## Next diagnosed limit, not changed here

The protocol corrects the earlier mistaken claim that three definitions exhausted
the budget: the actual budget is eight. In this fresh run, both corpora reach 512
entries with three definitions. Edited `last_learn_size` is 512, old is 491,
and the learning interval is 32. `record()` refuses additional entries at the
512 bound; `options()` requires at least 32 new entries before abstraction.
Neither condition can become eligible again. Both final cycles are 300.

Thus later archived executions stop reaching the abstraction corpus. This is a
concrete next connection to repair and test, not evidence that adding a larger
archive would improve intelligence. It was deliberately not mixed into this
fixed-code cost experiment. The earlier negative generalization evidence in
[the editing report](DSL-SEMANTIC-EDIT-RESULTS-20260913.md) remains valid and is
not replaced by the syntax-cache speed result.

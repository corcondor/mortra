# MORTRA 接円四辺形・第二接線の厳密チャート実験

## 目的

HAGeo固定89問の残り25問が、既存問題と全く異なる数学を要求しているのか、それとも既知の円・接線・外心構造を長く接続する共通変換が不足しているのかを判定する。対象は未認証の `2024KoMaLA877` とし、問題ID、数値座標、期待解答に依存しない証明器で追加正答を得られるかを検証した。

## 仮説

この問題には新しい述語はほぼない。停止原因は、次の既知構造が別々に存在し、一つの証明として接続されていないことである。

1. 1つの円への4本の接線が作る接円四辺形
2. 対角線に平行な接線
3. 外部点から引いた2本目の接線
4. 3点の外接円の中心と接点を結ぶ中心線

これらを接点パラメータの共通チャートへ落とし、入力条件から結論までの多項式恒等式を作れば、探索候補を増やさずに証明を閉じられると予想した。

## 原理

相似変換と回転により、内接円を中心 `I=(0,0)`、半径1の円とする。円上の点と、その2点における接線の交点を

```text
U(x)=((1-x^2)/(1+x^2), 2x/(1+x^2))
J(x,y)=((1-xy)/(1+xy), (x+y)/(1+xy))
```

で表す。4つの接点を `p,q,r,w` として

```text
A=J(p,q), B=J(q,r), C=J(r,w), D=J(w,p)
```

と置く。対角線 `AC` に平行な接線の接点を `S=U(u)`、外部点 `P` からのもう一つの接点を `T=U(v)` とすれば `P=J(u,v)` である。

`S` の接線が `AC` と平行である条件を `F=0`、`P` が `BD` 上にある条件を `G=0` とする。`G` は `v` の一次式であり、その係数を `K` とする。また、`A,T,C` の外心が `IT` 上にある条件の分子を `H` とする。

厳密な多項式除算により、126項の多項式 `Q` が存在して

```text
K^2 H + (p-q)^2(p-r)(q-w)(r-w)^2 F = QG
```

を得た。JGEXで `P` が2直線の交点として正常に構成されることから `K != 0` である。したがって `F=G=0` なら `H=0` となる。クラメルの公式を一般形で再生すると、`H=0` は `I`、`T`、三角形 `ATC` の外心が一直線上にあることと一致する。よって2円は `T` で接する。

## 実装方法

1. `triangle`、`circumcenter`、`on_circle`、`on_tline`、`on_line`、`reflect` の依存関係だけで構成を照合した。
2. 点名を変えた同型入力でも同じ役割を復元するようにした。
3. 平行条件 `F`、交点条件 `G`、結論条件 `H` をSymPyで再構成した。
4. 多項式除算の余り0、接線上条件、反射が第二接点になる恒等式、クラメル公式を計20本の残差として再生した。
5. 商 `Q` は証明に不要な因数分解をせず、126項とSHA-256を保存した。
6. 同じ証明書から問題の構成図と可読証明を生成した。
7. 証明ファイル、入力、チャート、適用証明のハッシュ連鎖を独立監査器へ追加した。

問題名、期待解答、目標に応じた特別な分岐は実装していない。

## 対照実験

| 入力 | 結果 |
|---|---:|
| 点名をすべて変更した同型構成 | 証明成功 |
| 目標を `coll` から無関係な `perp` へ変更 | 不採用 |
| `AC` と平行な接線条件を削除 | 不採用 |
| 元の `2024KoMaLA877` | 証明成功 |

したがって、問題名や答えを記憶して通しているのではなく、必要な構成と条件が揃った場合だけ証明が発火する。

監査済み固定89問の集合和は次のように更新された。

```text
64/89 = 71.91%

```

初期の40/89からは25問増、正答率は約28.09ポイント上昇した。

集合和の全履歴を再監査した結果、母集団外の加算0、空虚な単位イデアルによる除外0で、65問すべてが固定89問内の証明書付き結果として残った。

## 考察

性能上昇は実在する。一方、残りが全く違う種類の問題へ切り替わったわけではない。前段の一括監査では、未認証側の目標述語はすべて認証済み側にも存在し、構成語彙も23種中22種が共通していた。違いは、円・外心・接線を含む構成節が増え、複数の条件を一つの結論へ合流させる経路が長いことである。

今回の追加正答は、探索深度や候補数を増やした結果ではない。既に入力にあった構造を、接点パラメータという一つの表現へ移し、平行、接線、外心の間を一つの恒等式で接続した結果である。これは残り24問に対しても、各問題専用解法ではなく、再利用可能な構造チャートを増やすべきだという証拠になる。

ただし、この一つのチャートだけで残り24問が解けるとは主張しない。未解決集合には、別の円構造、角度・比への変換、順序や内外の枝条件、長い局所消去が混在する。次は同じ監査手順で、複数問題に共通する次の構造を選ぶ必要がある。

## 結論

不足していたのは新しい分野全体ではなく、既知の円・接線・外心を結ぶ実行可能な共通変換だった。接円四辺形と第二接線の構造を問題非依存の厳密チャートとして実装し、未解決問題を1問追加認証した。MORTRAの現在の監査済み総合値は65/89である。

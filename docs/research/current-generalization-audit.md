## C. 一致しなかった点

**1. CAS の「過去問300問で55問（18.3%）」は数字としては出たが、意味が無い。**

全件（5,369）に広げると内訳はこうなる。

```
打ち切り        1804  33.6%
記号が多すぎる    1438  26.8%
関係式が多すぎる    436   8.1%
```

**68.5% は投げる前に捨てたか6秒で打ち切ったもの。** 数学が届かなかったのではなく試していない。
さらに「解けた」277問の中身に `x = t²+1`、`a = a`、`b = -ax+f-x²` のような、
問題の答えではない変形が混ざっている。

**2. 原因は CAS ではなく入力だった。**

mathexamtest.jp の問題文はネイティブ MathML（1ページ約200要素）。
収集器がタグを剥いで平文にしていたため、意味を運ぶ構造が消えていた。

```
剥いだ後   log x x - 1
MathML    log x <= x - 1

剥いだ後   lim n n 1 2 log(1+x 1 n 2) dx
MathML    Limit(n*Integral(log((1+x**(1/n))/2), (x, 1, 2)), n, oo)
```

不等号も積分区間も消えていた。さらに `∠ABC` を `A*B*C` と読んでいた。
`mathml_to_sympy.py` と記号の畳み込みで修正済み。

**3. 純粋な平面幾何は入試にほとんど無い。**

5,369問から座標・ベクトル・曲線・立体・面積・不等式・三角比を除くと **9問**。
接続幾何を磨いても入試ベンチの分母が作れない。実力ではなく問題の分布の問題。

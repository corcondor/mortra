# MORTRA 型付き融合計画器と有限状態・有理角チャート

## 目的

MORTRA の融合生成を、個別の生成器を固定順序で試す方式から、親問題が持つ数学構造に基づいて合成規則を選ぶ方式へ変更する。

今回の評価対象は、二階の整数漸化式と有理角を含む問題族である。問題番号、変数名、係数、初期値、角度の分母が変わっても、同じ合成規則で厳密な融合問題を生成できるかを測る。

## 仮説

二階の整数漸化式は、法 $2q$ の順序対を状態とする有限状態遷移へ変換できる。有理角 $\theta=p\pi/q$ の余弦は、同じ法 $2q$ の有限巡回状態上の観測量になる。

したがって、次の二つの変換を同期して合成すれば、親問題ごとの規則を追加せずに融合問題を生成できる。

1. 整数漸化式を遷移行列と有限状態軌道へ変換する。
2. 有理角を有限巡回状態へ変換し、位相 $r$ と $-r$ を同じ余弦値として同一視する。

## 原理

漸化式

\[
u_{n+2}=a u_{n+1}+b u_n
\]

に対し、状態を $v_n=(u_n,u_{n+1})\bmod 2q$ とする。遷移は行列

\[
A=\begin{pmatrix}0&1\\b&a\end{pmatrix}
\]

で表される。状態数は高々 $(2q)^2$ 個なので、軌道は必ず最終的に周期へ入る。

一方、$\theta=p\pi/q$ なら、$\cos(u_n\theta)$ は $u_n\bmod 2q$ だけで決まる。さらに余弦の対称性により、位相 $r$ と $-r$ は同じ観測値を与える。

この構成が追加するのは、問題固有の数学対象ではない。既存の線形写像、合同類、有限状態、巡回位相の間を結ぶ再利用可能な変換規則である。

## 実装方法

### 型付き端点の抽出

各親問題から、利用可能な数学構造を抽出する。現在の計画器が扱う端点は次の9種類である。

- 一変数多項式の根配置
- 一次分数変換
- 座標平面上の円
- 正の二階漸化式
- 整数係数の二階漸化式
- 三角関数の冪和
- 有理角
- Pell 方程式の軌道
- 証明書付き厳密スカラー値

合成規則は問題番号を参照しない。各規則は必要とする二つの端点型を宣言する。計画器は異なる親問題から適合する端点を割り当てる。

### 有限状態・有理角チャート

有限状態・有理角チャートは次の処理を行う。

1. 初期値と二つの係数を保存したまま、二階漸化式を型付けする。
2. 有理角の分母から法 $2q$ を定める。
3. 合同状態を完全列挙し、状態軌道の循環開始位置と周期を求める。
4. 余弦による同一視を適用し、観測列の最小周期を求める。
5. 周期の真の約数をすべて検査し、周期の最小性を確認する。
6. 二進法による行列累乗で全状態を独立に再生する。
7. どちらかの親問題を除くと出力が定まらないことを確認する。

### 生成問題の監査

公開経路へ返す前に、生成問題を次の7条件で監査する。

1. 厳密な計算機構で解が求まる。
2. 別の検証経路でも証明書を再生できる。
3. 各親問題から抽出した条件に証拠がある。
4. 二つ以上の親問題が最終目標まで追跡できる。
5. 異なる親問題の構造を結ぶ合成操作がある。
6. 生成した問題文が親問題文の再掲ではない。
7. 証明が3段階以上あり、合成操作を実際に含む。

いずれかを満たさない候補は、親問題の単純な逆再生として公開結果から除外する。

## 評価方法

測定対象は `全問題.tex` の90問から作る、相異なる2問の全4,005組である。80問には、MORTRA が保存した検証済み解答と証明書を対応付けた。

変更前の比較値には、生成監査を追加する直前の同じ90問、同じ4,005組の結果を使った。問題識別子や表層文型を条件にした分岐は使用していない。

## 結果

| 指標 | 変更前 | 変更後 | 差 |
|---|---:|---:|---:|
| 構造から直接生成できた組 | 4組 / 4,005組 | 11組 / 4,005組 | +7組 |
| 証明済みの答えを合成できた組 | 105組 / 4,005組 | 105組 / 4,005組 | 0組 |
| 合計 | 109組 / 4,005組 | 116組 / 4,005組 | +7組 |

構造から直接生成できた組数は2.75倍になった。全4,005組に対する割合は約0.100%から約0.275%へ増えた。

新しい7組は、問題53のフィボナッチ型漸化式と、問題1、5、18、25、64、79、85に含まれる有理角との組合せである。

生成できた116組では、次の結果を得た。

- 生成監査に合格: 116組 / 116組
- 単純な逆再生と判定: 0組 / 116組
- 厳密計算、独立検証、親問題除去試験の全条件に合格: 116組 / 116組
- 証明の段階数: 最小7段階、最大10段階

測定結果は `artifacts/benchmarks/certified-fusion-fullproblems-20260831-generation-audit.json` に保存した。検証済み解答の対応表は `artifacts/benchmarks/fullproblem-certified-catalog-20260831.json` に保存した。

## 汎化性の検査

次の変更に対して、同じ実装が再計算を行うことを単体試験で確認した。

- 親問題の入力順を入れ替える。
- 問題識別子を変更する。
- 漸化式の係数と初期値を変更する。
- 有理角の分母を変更する。
- 三つ以上の親問題から、適合する二つの親問題だけを選ぶ。

答えを固定した分岐は実装していない。係数または角度を変更すると、構造識別子と答えの周期が変化する。

## 考察

今回の改善は、問題ごとに表現を追加した結果ではない。既存の数学構造の間に、入力型と出力型が明示された合成規則を追加した結果である。

一方、116組という数値は、116問すべてが人間にとって自然で独創的であることを意味しない。特に、厳密な二つの答えから共通の二階漸化式を作る105組は、正しさと両親依存性を満たすが、問題形式の多様性は低い。

構造から直接生成した11組は、親問題の途中構造を合成している。この11組は、答えだけを再利用する105組よりも、MORTRA が目標とする融合生成に近い。

次の改善では、生成済み問題全体との構造的重複検査と、証明グラフから必要最小限の前提を抽出する処理を追加する必要がある。これにより、正しさだけでなく、新規性と条件の自然さを測る。

## 結論

固定順序で生成器を試す方式は、型付き端点と合成規則に基づく計画器へ置き換えられた。有限状態・有理角チャートは問題番号に依存せず、90問の全組合せで新たに7組を厳密生成した。

生成できた116組は、証明グラフ監査をすべて通過した。ただし、現在確認できた汎化範囲は、実装済みの9端点型と8合成規則に限られる。

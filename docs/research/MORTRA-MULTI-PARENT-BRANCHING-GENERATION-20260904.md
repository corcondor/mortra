# 独立した二親入力からの分岐問題生成

日付: 2026-09-04

## 仮説

左右二つの整数写像を一つの問題文にまとめなくても、それぞれを独立した親問題として型付き入力へ写し、両方を必要とする深い分岐問題を生成できる。

## 方法

公開入口へ次の二問を別々に入力した。変数名も意図的に変えた。

\[
L(x,y)=(x+y,y),\qquad R(u,v)=(u,u+v).
\]

意味解析は各写像を `L` または `R` の入力端子へ割り当てる。生成器は次を拒否する。

1. 同じ親IDの重複
2. `L` または `R` が欠ける入力
3. 一方の親を使わなくても成立する二親入力
4. 二問を超える入力

受理後は、各親の証明義務、二入力を消費する橋、構造縮約、厳密解、SHA-256証明書を生成する。完成済みの問題や保存済みの答えは参照しない。

## 結果

公開入口から4問を要求し、次の4問を生成した。

1. 四次対称量の極限
2. 右写像を連続して使わない座標和の極限
3. `LLL` と `RRR` を禁止する座標和の極限
4. `LRL` と `RLR` を禁止する座標和の極限

全4問で次の条件を満たした。

- 親IDを2件とも保存
- 親から入力端子への割当を2件保存
- 合成則の項数は2
- 親証明は完備
- 未解決義務は0
- 能力の由来は実行時に合成した証明プログラム
- 探索継続なし

ブラウザ操作でも同じ二問を入力し、生成状態 `complete`、8件の検証済み証明義務、証明書ハッシュの表示を確認した。生成APIはHTTP 200を返し、ブラウザのエラーは0件だった。

関連する自動検査は37/37、型検査は成功した。再現ベンチマークは `passed: true` である。

## 文法探索の再検査

二文字 `L,R` の禁止語文法を再走査した。同一視後43種類、モーメント次数1から4まで172ケースを検査した。

- 深い構造の条件を通過: 88/172
- 一次式・二次式だけへ因数分解可能: 6/172
- 三次以下の因子だけへ縮約可能: 8/172
- 遷移行列の特性多項式から得る漸化式の検証: 172/172
- 観測列の最小漸化式の検証: 172/172
- Cayley–Hamilton 証明書の検証: 172/172

## 結論

一つの文章に二写像を埋め込んだ入力だけでなく、独立した二問を二つの入力端点として保持したまま、両方を必要とする問題と証明を生成できた。これは複数親入力の一般解ではなく、二つの相補的な写像に対する再現可能な最小例である。

初回実験で残った課題は、写像名に依存しない代数的作用の抽出と、三次以下へ縮約できなかった164ケースに対する中間補題の探索であった。

## 追試: 写像名からの独立

写像名への依存を除くため、認識条件を `L` と `R` という文字列から、二変数一次写像の成分構造へ変更した。追試では

\[
F(p,q)=(q+p,q),\qquad G(s,t)=(s,t+s)
\]

を別々の親として与えた。関数名、変数名、和の順序は元の入力と異なる。生成した二問の解答と合成指紋は標準名の入力と一致し、両親の証明も完備した。一方、`F(p,q)=(p+2q,q)` のように係数を変えた写像は受理しない。

これにより、次の未解決点は写像名ではなく、単位せん断以外の一般の整数一次作用を同じ生成器へ渡すための基底変換と不変量探索になった。

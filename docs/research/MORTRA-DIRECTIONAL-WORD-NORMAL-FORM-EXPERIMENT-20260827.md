# MORTRA 方向語・多表現・生成元正規形実験（2026-08-27）

## 目的

幾何以外の分野へ進むたびに分野固有の巨大な表現系を追加するのではなく、既存の型と少数の生成元から複数表現を導出できるかを検証する。

今回の問いは二つである。

1. 一つの有限語から、幾何・代数的支持・実行順序・行列作用を同時に作れるか。
2. 巨大な操作空間を、保存する不変量を明示した少数生成元の正規形へ圧縮できるか。
3. 同じ有限生成作用を、幾何だけでなく整数合同式と漸化式へ再利用できるか。

数オリ正答率や量子符号性能を直接測る実験ではない。まず共通表現核が本当に機能するかを独立に切り出した。

## 仮説

- **H1: 一構造・多表現**。方向語 `D=d_1...d_w` を一度だけ型付けすれば、同じ順序を保ったまま幾何経路、候補支持集合、局所実行スケジュール、アフィン行列作用へ移せる。
- **H2: 語彙を増やさず分野を増やせる**。新しい `MathSort` を追加せず、既存の `Sequence / VisualElement / Stabilizer / Matrix` と4生成元 `N/E/S/W` だけで実装できる。
- **H3: 正規形には商の宣言が必要**。終点だけを保存する正規形は行列作用には使えるが、支持集合や実行順序には使えない。この境界を証明書に書けば、誤った圧縮を拒否できる。
- **H4: 外部状態を固定すれば長時間実験を再開できる**。入力と実験コードのSHA-256、処理位置、集計値を原子的に保存すれば、会話コンテキストに全履歴を戻さず再開できる。
- **H5: 同じ作用核を異分野で共有できる**。方向語の並進、合同式の加法、漸化式の遷移行列を、いずれも有限状態への生成元作用として扱える。

## 一次資料と再現

### CSS Clifford回路の構造定理・正規形

- Victor V. Albert, [Beyond transversality: structure of Clifford circuits for CSS codes](https://arxiv.org/abs/2608.05688)
- [公式repository](https://github.com/valbert4/two-fold-transversal), commit `813862cd0a990ddb6b2ef9eff3126551d892f2b1`

公式コードをそのまま実行した。

| 公式検査 | 結果 |
|---|---:|
| 保存証明書の独立再検証 | PASS |
| `Sp(2,2)` | 6状態、終端2、最大距離1 |
| `Sp(4,2)` | 720状態、終端16、最大距離3 |
| 保存証明書を読まない全再構成 | PASS |
| 表・要旨・保存certificateのcross-check | 754成功、0失敗 |

MORTRAが取り入れたのはCSS符号の定理そのものではない。取り入れたのは、有限生成作用を全列挙し、各状態へ最短かつ決定的な代表語を保存し、別実装で到達性・最短性・正規性を再構成する証明書形式である。

### Directional Tile Codes

- [Nearest-neighbour gates are all you need: High-rate quantum low-density parity-check codes on a planar grid](https://arxiv.org/abs/2606.19482)

論文では一つの方向語が、正方格子上の経路、CSS stabilizerの支持、最近接測定の時間順序を同時に与える。重み `w` の語に対して相互作用深さは `w`、準備と測定を含む一巡は `w+2`、次の巡回は逆語を用いて配置を戻す。

ただし有効なdirectional CSS codeには、primal/dualの相互可換条件と変位ベクトルの偶奇条件も必要である。今回のMORTRA実装はこの二条件を検査していないため、出力を「候補支持」と明示し、符号性能を主張しない。

### Prime Agent

- [Prime Agent](https://arxiv.org/abs/2608.23552)
- [公式repository](https://github.com/PrimeIntellect-ai/prime-agent), commit `bc0fa7606abb3b7af0f765319518d255e6ae553d`

持続REPL、daemon、disk-backed stateという考え方から、今回の実験には入力ダイジェスト付きの原子的checkpointを導入した。Prime Agent本体をMORTRAへ組み込んだという意味ではない。

### 今回採用しなかったもの

Lie-group diffusionの「対象の多様体に計算空間を合わせる」原則は妥当だが、今回の作用は平面の離散並進であり `SU(2)` を必要としない。実タスクが無い段階でmanifold型を追加すると、最小表現という目的に反するため実装しなかった。

## 実装方法

### 一構造・多表現コンパイラ

`lib/mortra/cross-domain/directional-word.ts` に以下を実装した。

```text
DirectionalWord : Sequence
  -> GeometricPath       : VisualElement
  -> CandidateSupport    : Stabilizer
  -> MeasurementSchedule : Sequence
  -> TranslationAction   : Matrix
```

すべて同じ `steps` を消費し、各射は保存する不変量と証明書を持つ。新しい `MathSort` は追加していない。

TeX入力 `N^2 E S E N^2`、コンパクト入力 `NNESENN` の双方を字句解析する。支持集合に同じ辺が再登場した場合は `simpleEdgeSupport=false` とし、valid CSS codeと誤表示しない。

### 有限生成作用の正規形

`lib/mortra/kernel/canonical-generator-normal-form.ts` に分野非依存の有限作用atlasを実装した。

1. 初期状態と有限生成元を受け取る。
2. 生成元順序を固定したBFSで到達状態を全列挙する。
3. 最短語が複数ある場合は生成元順で最初の語を正規代表にする。
4. 検証器はatlasを定義から再構成し、経路再生、到達完全性、距離最小性、代表語の決定性、集計値を照合する。

方向語については、終点と並進行列だけを保存する商正規形も作った。証明書は `ordered-support / stabilizer-support / measurement-schedule` を保存しないと明記する。

### 凍結評価

`N/E/S/W` の長さ1から6までを全列挙した5,460語と、論文の重み7/9/11/13の4例を凍結した。期待出力表は使わず、次の独立実装で照合した。

- 座標の逐次加算
- 無向辺集合の直接構成
- 逆語の直接構成
- 3x3同次並進行列

さらに全例で証明書の行列を改変し、古い証明書を受理しないか検査した。

### 整数・漸化式adapter

`lib/mortra/cross-domain/generated-action-adapters.ts` で、既存チャートを同じ有限生成作用interfaceへ接続した。

```text
一次合同式 ax=b (mod m)
  0 --(+a)--> a --(+a)--> 2a -- ... in Z/mZ
  bが到達可能 <=> gcd(a,m) divides b
  bへの最短語長 = 標準基底解

アフィン漸化式
  s_n --T--> s_{n+1}
  Tは同次座標を含む随伴行列
  有限軌道の前周期・周期で巨大な添字を縮約
```

数値状態 `0` を偽値として「状態なし」と誤認する共通検証器の不具合が、この接続で初めて表面化した。`undefined` の明示判定へ修正し、幾何オブジェクトだけでなく数値状態でも同じ検証器を使えるようにした。

二つ目の凍結評価では、法2から40の全一次合同式22,139件と、法2から16の全一次アフィン漸化式18,495件を使用した。合同式は全剰余代入、漸化式は直接軌道列挙を独立oracleとした。

| 項目 | 結果 |
|---|---:|
| 総入力 | 5,464 |
| 4表現すべて独立検算と一致 | 5,464/5,464 |
| 幾何経路 | 5,464/5,464 |
| 候補支持 | 5,464/5,464 |
| 実行順序 | 5,464/5,464 |
| 行列作用 | 5,464/5,464 |
| 改変証明書の拒否 | 5,464/5,464 |
| 誤受理 | 0 |
| 新規 `MathSort` | 0 |
| 単純な辺支持を持つ候補 | 1,396 |
| 終点商が支持を失う実例 | 5,380 |

全語の元の長さ合計は30,988記号、終点だけを保存する正規形は14,344記号で、**終点作用という限定された商では53.711%短縮**した。ただし5,380件で支持集合が変わったため、この短縮率を問題全体の圧縮率とは呼ばない。

四表現が別々に同じ語を保持する単純モデルでは123,952 step-copyが必要だが、共有語から射を出す実装では30,988であり、表現間の重複は75%減る。これはメモリ実測ではなく、step表現の重複個数に対する構造上の計数である。

有限トーラス `(Z/7Z)^2` では49状態を完全列挙し、最大正規形距離6、独立再構成エラー0だった。長さ15の語を同じ作用を持つ長さ1の代表へ縮約し、経路を再生できた。

## 考察

### 支持された仮説

- H1: 4表現が全件一致した。
- H2: 新しい型を増やさず、既存4型と4生成元で実装できた。
- H3: 終点正規形が支持を失う反例を5,380件検出し、商の境界を機械的に示せた。
- H4: 実験コード自身と入力のダイジェストに結びついたcheckpointを実装した。
- H5: 幾何、整数、漸化式の三領域が同じ生成作用・到達性・正規形検証器を通った。

### まだ示していないこと

- IMO幾何や既存89問の追加正答。
- 有効なCSS code、距離、fault tolerance、論理Clifford作用。
- 任意の数学問題を4記号へ還元できること。
- 実時間やメモリが75%改善すること。
- 正規形が支持・順序・証明DAGまで保存すること。
- 高次合同式、非線形漸化式、大きな状態空間。明示atlasは上限を超えたら棄権する。

したがって、今回の結果は「最小表現から他分野の構造を再構成する核」の成立証拠であり、MORTRA全体の作問・証明性能の完成証拠ではない。

## 結論

一つの方向語を既存の4型へ移す共通意味核と、有限生成作用の証明書付き正規形を実装した。5,464件の方向語評価で4表現すべてが独立検算と一致し、誤受理は0だった。さらに同じ作用核を整数合同式22,139件と漸化式18,495件へ接続し、合計40,634件すべてで独立解と一致した。分野を増やすために型を増やすのではなく、同じ生成作用から必要な表現へ射を出す方針が、三領域の有限問題で成立した。

次の本質的実験は、既存の幾何作図列を同じ生成作用interfaceへ写し、未証明の凍結幾何問題で、正規形と表現共有を有効化した処置群と無効化した対照群を比較することである。追加正答、探索状態数、証明書再生率の三つが改善した場合だけ、数オリ性能への効果を主張する。その後に `付値/合同式` と `漸化式/行列` を同じ生成作用interfaceへ接続する。

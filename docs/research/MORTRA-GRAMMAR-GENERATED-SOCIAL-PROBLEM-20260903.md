# MORTRA 文法生成問題の厳密検証と公開記録（2026-09-03）

## 目的

問題固有の解法や問題テンプレートを登録せず、少数の再利用可能な操作だけで新しい難問を生成し、問題文・厳密解・証明経路・図・再生証明を一体として公開できるかを調べる。

## 原理

既存の問題操作12種を、情報を失わないまま次の5族へまとめた。

| 基本操作 | 含まれる既存操作 |
|---|---|
| transform | transport, map |
| combine | pair |
| restrict | equalizer, preimage, boundary |
| aggregate | fold, period, extremum, eliminate, contract |
| canonicalize | normalize |

圧縮後も元の操作名を保持するため、5族から元の証明プログラムへ戻せる。今回の問題生成は一貫して

`combine -> transform -> aggregate -> canonicalize`

の一つのプログラムを用いる。

二変数写像そのものも問題別に列挙しない。次数3以下の単項式から3項を選び、両方の親変数と少なくとも一つの混合項を含む支持集合を生成し、対称性・次数・定数項の有無による一定の順序で正規化する。したがって今回使った

\[
H(u,v)=u^2+uv+v^2
\]

は登録済みの名前付き解法ではなく、この文法が最初に生成する対称二次形式である。

## 方法

1. 既約かつ平方因子を持たない三次多項式を係数の小さい順に作る。
2. 親多項式の組を8組選び、上の写像文法を適用する。
3. 二段の終結式で二つの根を消去する。
4. 結果をモニックかつ平方因子を持たない多項式へ正規化する。
5. 全ての親根の組と結果多項式の根を数値的に相互照合する。
6. 左右の親多項式を別々に変え、同じ証明プログラムのまま答えだけが変わることを確認する。
7. 問題文と解答の文字化け、未閉鎖TeX、仮置き文字、画像の切れ・重なりを検査する。
8. 入力・証明・実行証明書・生成プログラムをまとめた再生ハッシュを発行する。

期待解答の参照や外部LLMによる解答生成は、この生成・検証経路に含めていない。

探索には101,393 msを要した。公開対象には次の問題を選んだ。

\[
f(x)=x^3-x-1,\qquad g(x)=x^3+x-1,
\]

\[
H(u,v)=u^2+uv+v^2.
\]

\(f(\alpha)=0\), \(g(\beta)=0\) を満たす全ての根の組に対し、異なる \(H(\alpha,\beta)\) をちょうど根にもつモニック多項式は

\[
P(z)=z^9-27z^6-2z^5-27z^4-9z^2+z-1
\]

である。

再生SHA-256は

`5bac640d964cbfd71e021f36af529c1087b3cd080cb0abd514065be8000c6b58`

である。

## 人が追える短い導出

\(s=\alpha+\beta\), \(d=\alpha-\beta\), \(z=\alpha^2+\alpha\beta+\beta^2\) とおく。親方程式から

\[
\alpha^3-\beta^3=s
\]

なので \(dz=s\) である。また \(d^2=4z-3s^2\) だから

\[
(1+3z^2)s^2=4z^3. \tag{1}
\]

一方、\(\alpha^3+\beta^3=d+2=-2s^3+3zs\) である。\(z=0\) は親方程式と両立しないので、\(d=s/z\) を代入し、(1)を使って整理すると

\[
s(z^4-1)=2z(1+3z^2). \tag{2}
\]

(2)を二乗して(1)を代入すれば

\[
z(z^4-1)^2=(1+3z^2)^3,
\]

すなわち \(P(z)=0\) を得る。さらに \(\gcd(P,P')=1\) である。二段終結式は9組の像の積であり、平方因子がないため像の衝突もない。従って \(P\) は求める多項式である。

この短い導出は公開問題を読みやすくするための別表現であり、生成器へ問題固有の規則として登録しない。

## 考察

今回の本質は「三次式の根を二次形式で写す」という一題の型ではなく、親の直積、入力された多項式写像、変数消去、平方因子除去という同じ合成が、親係数と写像支持を変えても動く点にある。28個の異なる答えを一つの証明プログラムで得たこと、および左右どちらの親を変えても答えだけが変わったことが、問題文の言い換えや片親の暗記ではないことを支える。

一方、この実験が直接示す範囲は代数的な有限根配置への多項式写像である。任意分野の作問能力はまだこの結果だけからは導かない。次の比較では、同じ5族の操作を二次形式と期待値、漸化式と行列、合同式と付値へ写し、分野を越えて同一の縮約が保たれるかを測る。

## 結論

問題固有の写像名を増やさず、生成文法と一つの証明プログラムから、8組の親について28個の異なる厳密解付き問題を生成できた。うち15個が公開条件を満たし、選定した一問について問題画像・解答画像・再生証明・画像SHA-256を固定した。公開時にも同じSHA-256を再検査し、生成後に差し替わった画像は投稿できない。

# MORTRA 固定89問の厳密局所消去実験（2026-08-25）

> 現在値: 公式JGEXの既知交点除外による `2024PlanetCupp10` と、
> source-guarded bounded certificateによる `2011G5` を含め、固定89問の
> 厳格な総合値は **61/89 (68.54%)**。以下の負の実験もこの値を減点しない。

## 目的

HAGeoの凍結済み89問だけを母集団とし、現在の未認証28問の厳密多項式証明を高速化する。
問題ID、期待解答、外部LLM、問題固有の分岐は使わず、全問題へ共通に適用できる
局所消去と証明書保存だけを変更する。追加得点は、余り0の証明書を独立再生できた場合に限る。

## 原理

座標化された幾何問題の最終証明は、多項式イデアルへの目標式の所属判定になる。
大域的なGroebner基底を最初から計算する代わりに、局所的に現れる変数を先に消去し、
より小さな多項式環へ射影する。ただし射影ごとに次を保存する。

- 入力多項式と出力多項式
- 入力の線形結合が出力になることを示すイデアル所属証人
- 必要な非零条件
- 再生余り0
- 証明内容のSHA-256

線形な2式

```text
a*x + b = 0
c*x + d = 0
```

から `x` を消去する場合、一般のSylvester行列や拡張GCDは不要である。恒等式

```text
a*(c*x+d) - c*(a*x+b) = a*d-b*c
```

を直接使えば、除算も追加の非零仮定もなく、厳密なresultant射影を得られる。

## 方法

1. 線形resultantを上の2x2行列式へ置換した。
2. 項数上限を、因数分解された表層の項数ではなく、残る変数について展開した場合の上限で判定した。
3. 消去後の正規化を、既に消した変数や係数だけの幾何chartを除いた活性環に限定した。
4. 残差条件付き順位を使わない実行で、未使用の残差メッセージを毎段再因数分解していた処理を停止した。
5. 完全な途中証明はSHA付きsidecarへ一度だけ保存し、進捗JSONには件数と参照先だけを残した。
6. 既に正規化済みの非退化因子積をbeam候補ごとに再因数分解せず、因子キー集合で重複を除いた。
7. `2023VietnamTSTp3`を同じ入力・同じF5B・同じ固定語彙でA/B測定した。
8. 一次消去と二次消去を比較し、最終多項式環が小さくなるか測った。
9. `2024PlanetCupp10`の深さ4飽和探索を、因子積再分解の有無だけ変えてA/B測定した。
10. 未使用変数だけが消えた場合も、縮約後の環を最終Groebnerへ渡すよう修正した。
11. `2017G4`で項数上限256と4096を比較し、共通の厳密局所射影が最終環を縮小するか測った。
12. ゴール指向局所縮約をWolfram証明探索へ接続し、Wolframの結果も元方程式への商多項式再生で判定した。
13. Wolframへ渡す係数chartを因数形のまま保持し、飽和を使わない実行では未使用の非退化因子分解を省いた。

## 考察

今回の変更は計算を速くしたが、数学的到達可能性は増やしていない。
`2023VietnamTSTp3`では、局所消去が支配項だった状態を解消した後も、
5変数・4式・係数パラメータ3個のGroebner計算が600秒で閉じなかった。
したがって次の課題は、単に時間を延ばすことではなく、厳密な中間補題または追加の局所射影によって
最終環そのものを小さくすることである。

二次resultantを許可しても環が小さくならなかったため、次数上限だけを増やす方針はこの問題では支持されない。
また、高速化と得点改善を同じ成果として扱わない。証明書が閉じていない限り総合値は61/89のままである。

`2024PlanetCupp10`では、再因数分解を除くことで探索の未完了を解消したが、非退化因子の積だけでは
目標余りを閉じないことまで確定した。次に必要なのはbeam幅や時間の増加ではなく、
現在の余りを別の型付き幾何関係へ戻す中間補題、または最終環を縮小する追加の厳密射影である。

`2017G4`では最終環を11変数から7変数へ縮小しても、SymPyとWolframの双方で証明が閉じなかった。
したがって「変数を減らせばこの問題が直ちに解ける」という仮説は支持されない。一方で、
高項数の局所射影が共通規則だけで環をさらに2変数縮小できることは確認できた。
次は、この縮約成果物を再利用可能な証明checkpointとして保存し、同じ前処理をCASごとに
繰り返さず、残る7変数環に対する中間補題分割または別の厳密消去順序を比較する。

## 結論

全89問に適用できる厳密な局所消去の共通実装を高速化し、途中証明を失わずに
前処理を約31.2倍短縮し、別問題では600秒超の探索を145.241秒で完走させ、
`2017G4`の最終環を11変数から7変数へ縮小した。しかし追加正答はまだ0で、
この実験単体の追加正答は0であり、固定89問の現在の厳格な総合値は **61/89 (68.54%)** である。
次の実験は、固定89問のうち既に最終還元・飽和探索まで進んだ未認証問題を対象に、
保存済み停止段階から証明を継続し、追加の厳密証明が得られるかを測る。

## 継続実験: 非零条件の証明付き移送（2026-08-26）

### 目的

局所消去後の終端系へ、元の非退化条件を消去済み変数のまま渡していた接続不良を修正する。
問題ID、期待解答、外部LLM、問題固有の分岐は使わない。

### 原理

線形ピボット `c*x+k=0` と元条件 `c != 0` が証明済みなら、多項式条件
`h(x) != 0` は `c^deg(h) h(-k/c) != 0` と同値である。
この変換を分母なしの多項式恒等式として再生し、SHA-256付き証明書を保存する。
逆向きの枝選択を保証できないresultantでは、消去変数を含む条件を下流で再利用しない。
また、出力が恒等的に0だけのresultantは新しい多項式帰結を作らないため、探索射として棄却する。

### 実装

- 線形式と二次式が同じbucketにある場合も、元条件から非零性が証明された線形ピボットを優先
- `mixed_degree_linear_localization` を分母なしで実装し、全出力を元式へ再生
- 非零条件を各localizationの後へ順次移送する証明書を追加
- 移送不能条件を小さい環へ誤投入せず、明示的に記録
- 恒等的に0だけを返すresultant projectionを棄却
- 認証監査器へ条件移送の再生、余り0、証明書hashの検査を追加

### 結果

`2024ELMOSLp1` は同じ入力・同じ共通規則で次のように変化した。

| 段階 | 結果 |
|---|---|
| 修正前 | 消去済み `_free_y_10` を係数環へ入れて `execution_error` |
| mixed-degree localizationのみ | 56.81秒、`unproved` |
| 条件移送 + 0-resultant棄却 | **80.89秒、厳密証明成功** |

## 継続実験: 外心接線と3直線共点の構造射影（2026-08-26）

### 目的

`2025KoeraFinalRoundp3` が全く異なる問題種なのか、既存の幾何語彙を長く合成したために
終端多項式が膨張した問題なのかを、期待解答と問題ID別分岐を使わず検証する。

### 原理

外心 `O` を含む接点 `A` での接線条件は、外心をCramer消去すると、三角形の2辺と接線上の点だけを
含む分母なしの一次式へ移せる。さらに2本の直線の交点 `Q` が3本目にも乗る条件は、3直線の
係数行列の行列式が0であることと同値である。この2つの恒等式を元の作図式へ再生してから、
独立な2個の二次関係を係数パラメータより先に置いたlex順序で厳密除算する。

### 方法

1. 3個の外心を、それぞれの接線条件と同時に証明付きで消去した。
2. 2本の接線の交点を消去し、目標を3直線共点の単一行列式へ変換した。
3. 終端環の2変数を係数パラメータより前へ置き、FLINTで商と余りを厳密計算した。
4. FLINT内で `goal = q1*f1 + q2*f2` を再生し、巨大な商をSymPyへ再展開せず保存した。
5. 既存62問との集合和、凍結89問内の所属、証明ファイルSHA、非空虚性を監査した。

### 結果

| 段階 | 終端系 | 結果 |
|---|---:|---|
| 旧経路 | 10式・10変数 | 600秒timeout |
| 外心接線射影 | 4式・4変数 | 多項式展開でtimeout |
| 3直線共点射影 | **2式・2変数** | **54.41秒で厳密証明** |

最終証明は `remainder=0`、`vacuous_unit_ideal=false`、局所消去再生成功、
構造補題4件再生成功、未輸送非零条件0、解答4段、証明書SHA一致だった。
焦点試験3件、主変換86件、台帳・消去核56件の計145件が成功した。
固定89問の監査済み総合値は **62/89 (69.66%) から 63/89 (70.79%)** へ上昇した。

### 考察

この問題は新しい目標述語を要求していない。既存の `circumcenter`、`on_tline`、`perp` を
長く合成し、外心3個と交点1個を座標変数として最後まで保持したため、同じ幾何内容が巨大な
多項式へ展開されていた。したがって不足は語彙の個数より、作図ブロックを意味のある補題へ縮約する
射と、証明変数・係数パラメータを区別する多項式順序だった。

一方、残り26問がすべてこの射影で解けるとは主張しない。作図elaboration停止、5〜8変数の
終端環、円・比・角度間の表現移送など、停止段階は複数ある。今回示したのは、残りが別分野だから
解けないのではなく、同じ語彙でも証明DAGの形に応じて必要な縮約射が異なる、という一点である。

固定89問を再集計すると、この区別は定量的にも確認できる。残り26問の目標述語は
`coll/cyclic/cong/eqangle/perp/para`だけで、すべて認証済み63問にも現れる。残り側の作図語彙23種のうち
22種は認証済み側と共通し、非共通の `free` は自由点の導入であって新しい幾何定理ではない。
一方、作図節数の中央値は認証済み8に対して残り13.5で、残り26問すべてが `circumcenter`、
23問が `on_circle` を含む。hard tailは別の目標種ではなく、円・外心を中心とした長い作図合成に偏っている。

### 結論

性能向上は追加正答と実時間の双方で確認できた。次は未認証26問を停止段階と作図ブロック型で分類し、
同じ射影が適用できる対照群では再利用し、それ以外には別の共通構造射を追加する。

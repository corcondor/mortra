# ゴール周辺の証明内容を直接読む監査（2026-08-22）

## 目的

未解決問題の原因を、述語数・点集合の重なり・閉包サイズから推測しない。
実際のゴール、発火した結論、規則の具体的な前提を読み、どの数学的関係が欠けているかを確定する。

## 方法

- HAGeo探索の実枝（6段）を同じseedで再生した。
- Yuclidの `all_deductions` を全件取得した。
- `eqangle` を4本の無向直線の角度等式として比較した。
- 等式の左右交換と両角の同時反転だけを同値とした。
- `cong` は2本の無向線分の等式として比較した。
- `r01`、`r04`、`r52`、`r53`、`r74` の具体的なground前提を閉包へ照合した。

点名の集合だけを比較する旧 `max_overlap_with_goal_args` は原因分析に使用しない。

## 結果1: 2002CTSTp25

問題の構造は次である。

```text
A,B,C,D: 完全四辺形の4点
E=AB∩CD, F=AD∩BC, P=AC∩BD
O: PからEFへ下ろした垂線の足
目標: eqangle(A,O,B,O,D,O,C,O)
      すなわち ∠(AO,BO)=∠(DO,CO)
```

実枝が加えた6構成は `shift / intersection_pp / intersection_tt / midpoint / reflect / on_pline` だった。
閉包は3,858 deduction、`eqangle` 1,185件を生成した。

しかし、目標を構成する4直線 `AO, BO, DO, CO` と、同一の役割で一致する直線数は最大1本だった。
旧指標で「4点が重なる」とされた代表例

```text
eqangle(A,F,B,F,D,F,C,F)
```

は、外側の点名 `A,B,C,D` が同じだけで、必要な4直線をすべて `O` ではなく `F` で結んだ別の等式である。
数学的には目標への1段手前ではない。

ゴールを直接結論できる `r52/r53` のground候補では、非退化条件 `diff` はすべて数値確認済みだった。
未証明なのは各候補の `simtri` または `simtrir` 1件だけである。例:

```text
r52:
  simtri(A,O,B,D,O,C)  未証明
  diff(A,B,O)           証明済み
  diff(C,D,O)           証明済み
```

従って詰まりは「角度等式の量」ではなく、`O` を含む対応三角形の相似を作る構成・規則が無いことである。

## 結果2: 2022CHNSouthEastMOg11p6

目標は `cyclic(B,C,D,K)`。実枝が加えた6構成は
`lc_tangent / intersection_pp / on_tline / eqangle2 / eq_triangle / foot` だった。
閉包は1,830 deductionを生成したが、`cyclic` の結論は0件だった。

### r01（共通中心からの等距離）

閉包中の合同を直接照合すると、候補中心は分裂していた。

```text
中心 O: OB=OC は証明済み、OC=OD と OD=OK は未証明
中心 Q: QD=QK は証明済み、QB=QC と QC=QD は未証明
```

`O` は元の三角形の外心、`Q` は `AD` の中点であり、既知の等距離関係が別々の中心に属している。
`r01` を閉じる共通中心は存在しない。

### r04（円周角の逆）

同値な3つのground候補を直接確認した。

```text
eqangle(B,D,B,K,C,D,C,K)
eqangle(B,C,B,K,C,D,D,K)
eqangle(B,C,B,D,C,K,D,K)
```

4点非共線条件は数値確認済みだが、3つの角度等式はすべて未証明。
閉包中の最接近例でも、必要な4直線のうち一致は最大1本だった。

### r74（角の二等分線と垂直二等分線）

12個のground候補すべてで、`ncoll` と `nperp` の2ガードは数値確認済みだった。
一方、各候補に必要な `eqangle` と `cong` は12組すべて未証明だった。

したがって `r04/r74` は候補生成に失敗したのではない。候補は生成されているが、数学的な主前提が一つも閉じていない。

## 考察

旧表の「ゴール引数との重なり最大」は、点の役割・直線・角の向きを捨てていた。
そのため `O` と `F` を中心とする全く別の角度等式まで近いと数えた。

直接監査で分かった次の実装対象は、規則数や探索深度の一律増加ではない。

1. `2002CTSTp25`: `O` を含む2三角形の相似候補を後向き義務から構成する。
2. `2022...`: `OB=OC` と `QD=QK` を同じ円へ結ぶ中間構造、または3つの具体的円周角等式のいずれかを閉じる構成を生成する。
3. 候補評価は点集合重なりを廃止し、型付きの直線役割・等式役割・ground前提の充足数を使う。

## 結論

「規則が発火していない」「語彙が単純に不足している」という説明は不正確だった。
発火と候補生成は起きている。失敗は、ゴールを閉じるground前提と、実際に生成された関係の役割が一致しないことにある。

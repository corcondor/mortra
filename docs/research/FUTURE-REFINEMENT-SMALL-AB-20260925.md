### 不一致の根拠と制約

保存された経験と最終割り当てだけを使って、誤統合した対に対する最短の識別行動列を評価側で求めました。コアの再学習や行動の追加はしていません。

NEWの停止対象158対は、すべて少なくとも片側の正確な履歴から、その識別行動列が観測されていませんでした。これは「同じ真の状態・行動の辺を別の履歴で観測した」ことと、「現在混同されている履歴の区別を観測した」ことが異なるためです。

具体例は `historical_cue` の次の2履歴です。数字は意味を持たない観測・行動IDです。

```text
観測: [0, 2, 3, 3, 3]    行動: [0, 0, 0, 0]
観測: [1, 2, 3, 3, 3]    行動: [0, 0, 0, 0]
最終の学習block: 両方とも4
評価側の識別行動: [1]
真の次観測: 4 / 5
この正確な履歴から[1]を実行した経験: 両方ともなし
```

両履歴は4手の収集終点です。未知の続きに対する反例は入力されていません。今回の条件だけから、誤った同値認証や、完全な反例があるのに分割できないバグを断定することはできません。なお、初期の暫定的な観測状態への同一視と、認証後のmergeは別です。

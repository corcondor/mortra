# MORTRA HAGeo残り26問の意味条件監査

## 目的

固定89問で厳密認証済みが63問まで増えた一方、残り26問が別種類の数学なのか、既存構造の長い合成で止まっているのかを切り分ける。さらに、自然文からJGEXへ変換するときに作図の枝を決める条件が失われていないかを確認する。

## 方法

1. 認証済み63問と未認証26問の目標述語、作図語彙、作図節数を比較した。
2. HAGeo-409の自然文とAlphaGeometry/JGEX表現を問題ごとに比較した。
3. 最短の未認証問題 `2014CHNGaoLian` を座標化し、接線と円の交点の全分岐を厳密有理数で評価した。
4. Newclidの交点選択と問題妥当性判定の実装を直接確認した。

## 結果

### 残りは別分野ではない

- 未認証26問の目標述語は全て認証済み側にも存在する。
- 未認証側の作図語彙23種のうち22種は認証済み側と共通する。
- 作図節数の中央値は認証済み8、未認証13.5。
- 未認証26問全てが外心を含み、23問が円上点を含む。

したがって、主な差は新しい語彙ではなく、円・外心・交点を通る証明DAGの長さと分岐である。

### 自然文の意味条件がJGEXで失われる

`2014CHNGaoLian` の原文には次が明記されている。

- `ABC` は鋭角三角形。
- `angle BAC != 60 degrees`。
- `A` と `D,E` は直線 `BC` の反対側にある。

一方、JGEX表現は `triangle`、`on_tline`、`on_circle` だけで、半平面条件と角度条件を保持しない。

`A=(1/2,1), B=(0,0), C=(1,0)` とすると、この三角形は鋭角で `angle BAC != 60 degrees` である。接線と円の交点は

```text
D_epsilon = (-3 epsilon / 5, 4 epsilon / 5)
E_delta   = (1 + 3 delta / 5, 4 delta / 5)
epsilon, delta in {-1, 1}
```

と書ける。原文の半平面条件を満たす `epsilon=delta=-1` では厳密に `AM^2-AN^2=0` となる。しかし片方だけ別枝にすると

```text
epsilon= 1, delta=-1: AM^2-AN^2 = -5929/3600
epsilon=-1, delta= 1: AM^2-AN^2 =  5929/3600
```

であり、見えているJGEX等式だけからは結論が従わない。

### Newclidの数値作図は枝を暗黙選択する

Newclidの `reduce_intersection` は複数交点を独立にシャッフルし、既存点でない最初の点を返す。さらに `JGEXProblemBuilder` は `nc_problem_is_valid` で仮定だけでなく目標も数値検査し、目標が成立する配置が得られるまで再試行する。

これは数値図を作るには有効だが、可視のJGEX等式だけを前提とする厳密証明には使えない。目標を見て選ばれた枝を、目標から独立した仮定として扱うと循環になる。

### 残り26問の意味条件候補

自然文の機械的監査では、26問中16問に半平面、内外、順序、第二交点、鋭角などの語が現れた。全てが証明に必須とは限らないが、形式化で落ちた可能性があるため、単純な「未解決」と同一視してはならない。

## 考察

性能向上は実在する。固定89問は40問から63問へ増え、直近でも同じ語彙の構造縮約によって600秒超過だった `2025KoeraFinalRoundp3` を54.41秒で厳密証明した。これは探索量だけでなく、作図ブロックを型付き補題へ縮約する実装が効いた結果である。

一方、残りには少なくとも二種類の停止原因が混在する。

1. 等式としては成立するが、長い円・外心DAGを小さな中間補題へ分けられていない問題。
2. 自然文の向き・順序・枝条件が形式表現から落ち、可視の等式だけでは反例を含む問題。

後者を前者と同じように探索時間やGroebner深度で押しても解けない。先に形式化を直す必要がある。

## 結論

不足しているのは新しい幾何分野より、次の共通基盤である。

1. `same_side`、`opposite_side`、`between`、`ray`、`inside`、`second_intersection` の型付き意味IR。
2. これらを実数上の符号条件として保持する半代数的な枝証明書。
3. 目標を見ずに作図トレースから枝を固定する仕組み。
4. 円・接線・外心の局所補題を型付き関係へ戻し、長いproof DAGを縮約する機構。

次の実装は、原文の半平面条件を一般構文として取り込み、枝証明書を明示した場合だけ `2014CHNGaoLian` を再認証することである。問題IDや期待解答による分岐は使わない。

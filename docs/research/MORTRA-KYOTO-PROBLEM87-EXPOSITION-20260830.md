# MORTRA 問題87 京大適合性・解説出力監査 (2026-08-30)

## 目的

問題87の題材と要求水準が京都大学理系数学として不自然でないかを、実際の出題と公式方針から判定する。同時に、MORTRAの正答を答えだけでなく、途中式、数学図、使用した射、証明義務、再生可能な証明書として公開できる状態にする。

## 観察

1. 京都大学は、求値問題でも結論までの論理、必要十分条件、数学的表現を評価対象としている。
2. 2023年度第6問は、`cos(n theta)` を整数係数多項式へ移し、有理角と素数条件を結ぶ「三角関数と整数の融合問題」だった。
3. 同年度には誘導のない単問が複数あり、未知の構造を自分で見抜かせる形式自体は京都大学の実例と整合する。
4. 問題87も、有理角、三角関数の冪、合同条件、有限軌道を一つの証明へ結ぶ。題材の組合せは京都大学の範囲から外れていない。

## 判定

問題87は「京大では出ない分野」ではない。特に2023年度第6問との近さから、三角関数と整数の融合という題材には明確な実例がある。ただし、現在MORTRAが得た最短の完全証明は円分多項式の共役移送補題を使う。この補題を既知として要求するのは通常の高校課程を越える。

したがって運用は次のどちらかが妥当である。

- 本試験形式: 共役移送補題を前段の小問として証明させる、または使用可能な補題として与える。
- 挑戦問題形式: 問題文は現状のまま最終問題に置き、解説で補題を一から証明する。

難しいこと自体を理由に除外しない。一方、補題を隠したまま「高校数学だけの標準解法」と表示してはならない。

## 実装

問題87の実行証明書へ、次の6射と8証明義務を機械可読で保存した。

1. 円分共役移送と一様ノルム評価
2. 符号付き正弦条件による既約分母分類
3. 0水準と-1水準の閉包
4. 水準集合の八分円単調性と軌道上界
5. 交換自己同型による例外分母排除
6. 元の条件への厳密代入再生

解説出力では、数学図と証明ロードマップを別々に描画する。従来は数学図が「証明の経路」を上書きし、実行した射がPDFから消えていた。artifact version 2では、射の入力型・出力型・役割・ID、証明義務O1--O8、証明書SHA-256を自動掲載する。

## 結果

- 解は `(n,p,q)=(2,1,4)` のみ。
- 候補の総当たりではなく、共役移送、符号条件、既約分母分類、オイラー関数上界、2個の交換矛盾、代入再生で閉じた。
- 公開APIと構造定理核の回帰テストで、射6本と証明義務8件が出力へ保存されることを確認した。
- 解説PDFは問題、答え、9段階の証明、数学図、証明経路、射の役割、証明義務、証明書を同一成果物に含む。

## 結論

問題87の題材は京都大学型として成立しうるが、現状の完全証明は最難関・挑戦問題相当である。採用時には共役移送補題を明示し、採点可能な途中式を残す。MORTRAの製品出力も、答えの表示ではなく「どの構造変換が何を閉じたか」を読者が追える形式を標準とする。

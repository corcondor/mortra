# MORTRA 再利用可能な円関係チャート抽出実験

## 目的

固定89問の未認証23問を対象に、問題名や期待解答を記憶せず、複数の問題へ再利用できる表現チャートを抽出する。単に対象問題を座標計算で閉じるのではなく、次の条件を満たすものだけを証明能力として登録する。

1. 点名を全面変更しても同じ構造を認識する。
2. 操作の可換性、交点の順序、同値な半径点の選択を吸収する。
3. 接続を1本だけ変えた近接構造を誤受理しない。
4. 全ての恒等式と非退化条件を再生できる。
5. 固定89問全体で曖昧一致と母集団外加算がない。

外部LLMと期待解答は使用しない。

## 仮説

残りの問題には、局所的な角度追跡だけでは長くなるが、円束、根軸、アフィンな円族へ移すと短い恒等式になる構造が含まれる。したがって、問題ごとの定理を追加するのではなく、次の表現変換を独立したチャートとして実装すれば、同じ構造を持つ別入力にも再利用できると予想した。

```text
接円三角形 + 割線 + 中点
  -> 単位円上の有理パラメータ
  -> 円束
  -> 接触判別式

平行な二横断線 + 三辺への垂線
  -> 1パラメータのアフィン点族
  -> 係数が一次の円族
  -> 二円接触判別式
```

## 原理

### 1. 接円三角形・割線・中点チャート

内心または傍心を `I`、三辺への垂足を `D,E,F` とする。円 `Gamma1=AEF` と辺 `BC` の交点を `P,Q`、`M` を `AD` の中点とする。目標は、円 `Gamma2=MPQ` が接触円に接し、その共通点 `U` が二中心を結ぶ直線上にあることを示すことである。

接触円を単位円、`I=(0,0)`、`D=(1,0)` に正規化し、

```text
U(t)=((1-t^2)/(1+t^2), 2t/(1+t^2))
J(s,t)=((1-st)/(1+st), (s+t)/(1+st))
E=U(u), F=U(v)
A=J(u,v), B=J(v,0), C=J(u,0)
```

と置く。`Gamma1` を `x^2+y^2+b1*x+c1*y=0` と書けば、

```text
b1=(uv-1)/(uv+1)
c1=-(u+v)/(uv+1)
```

である。`BC` は `x=1` なので、`P,Q` を個別に解かず、両点を通る円束を

```text
Gamma2 = Gamma1 + lambda*(x-1)
lambda = -(u-v)^2/(4uv(uv+1))
```

と表す。`M` を代入してこの `lambda` を決める。最後に、円 `x^2+y^2+b*x+c*y+d=0` と単位円の接触条件

```text
(d+1)^2-b^2-c^2=0
```

を再生する。共通点が実在するため、根軸式と二次元の内積・外積恒等式から `I,O2,U` の共線が従う。

### 2. 平行横断線・垂線三円チャート

三角形 `ABC` を

```text
A=(0,0), B=(1,0), C=(p,q)
```

と正規化する。互いに平行な横断線を一つの族

```text
x+h*y=tau
```

で表す。この直線と三辺との交点 `X(tau),Y(tau),Z(tau)` は `tau` の一次式である。各交点から対応する辺へ引く三本の垂線の交点 `U(tau),V(tau),W(tau)` も一次式になる。

三点を通る円を

```text
x^2+y^2+b(tau)*x+c(tau)*y+d(tau)=0
```

と書くと、`b,c,d` は全て `tau` の一次式になる。異なる `tau1,tau2` に対する二円について、中心距離平方を `D2`、半径平方を `R1,R2` とすれば、接触条件は平方根を使わず

```text
(D2-R1-R2)^2-4*R1*R2=0
```

となる。共通点 `T` が入力で与えられているため、根軸と中心線の恒等式から `O1,O2,T` の共線が従う。

## 実装方法

1. JGEXを型付き構成列へ解析し、問題IDを参照せず役割を復元した。
2. `on_line`、`on_pline`、`on_tline`、`foot`、`midpoint`、`circumcenter`、`on_circle` の対称性を正規化した。
3. 接円三角形チャートでは内心と傍心を同じ「三辺から等距離の中心」として扱った。
4. 平行横断線チャートでは二つの横断線の交換、三垂線交点の役割、円の半径を示す三点の選択を同値として扱った。
5. 前者19本、後者33本の恒等式をSymPyで厳密再生した。
6. 各証明から可読Markdown、SVG、適用記録、証明書SHA-256を生成した。
7. 固定集合の未解決問題を全チャートへ再投入し、誤一致と曖昧一致を監査した。

## 失敗した候補

`2011G3` について、二つの直径円の共通点を `E=(-1,0),F=(1,0)` に正規化し、二組の三垂足円の根軸が中点を通るチャートを検討した。有理数例では二円の定数項が一致した。しかし、最初の一般式検査では円方程式の定数項ではなく一次係数を比較しており、偽の反例を生成した。この検査ミスを訂正した後も、4変数有理パラメータの完全展開は3分以上で完了せず、今回の再生可能な小証明書へ分割できなかった。

したがって `2011G3` は未認証のままとし、69/89へ加えていない。次回は円係数を直接全展開するのではなく、各垂足、二つの定数項、定数項差、根軸の4段に局所消去を分ける。

## 考察

今回有効だったのは、変換規則を大量に足すことではない。一つ目は二交点を個別に追わず円束へ縮約し、二つ目は六つの垂線交点を一つのアフィン円族へ縮約した。いずれも、長い構成を少数のパラメータと一つの接触判別式へ移す表現チャートである。

汎化を支えるのは点名ではなく、入出力型、構成の依存関係、操作の対称性、非退化条件である。名称変更と同値操作には不変で、接続を1本変えると失敗することを確認したため、少なくとも同型構造への再利用性はある。

ただし、両チャートは対象問題を見た後に実装した post-hoc 能力である。固定89問上の69/89は現在コードの監査済み能力和であり、独立未見集合に対する汎化率ではない。未見問題での追加正答を測るまでは、一般的な作図能力や任意問題解決能力とは主張しない。

## 結論

円・接線・垂線の複雑な構成から、二つの問題非依存な表現チャートを抽出した。52本の恒等式を全て再生し、名称変更と近接反例を含む91件の全チャート回帰を通過した。既存能力の集計漏れも修正し、固定89問の監査済み能力和は69/89となった。残る20問への誤一致は0である。

# MORTRA Model 1 親問題融合と公開UI実験

## 原理

公開UIは推論を演出しない。二つの親問題を別々の入力として保持し、各入力から得た
型付き対象と制約が、同じ実行可能な構造に必要であることを検査する。生成候補は
親依存性、重複、新規性、厳密計算、独立再計算を通過した場合だけ問題・図・解答・
証明書を一つの `ProblemArtifact` として返す。

表示する5段階は実APIイベントに対応する。

1. 構造化: `start / inducing / registering`
2. 候補生成: `searching / structuring`
3. 融合検査: `novelty`
4. 厳密検証: `verifying`
5. 保存: `saving / complete`

イベントが存在しない「意味解析完了」「型形成完了」は表示しない。探索時間の調整も
公開UIから除き、内部の実行予算として管理する。

## 実装

- ブランドを `MORTRA`、モデル表記を `Model 1` に分離した。
- 二つの親問題を左右対称に配置し、操作を `融合問題を生成` に一本化した。
- ランダムな線群を廃止し、2入力、対象・関係、不変量、橋渡し、候補・反例、証明書からなる
  12節点14辺の有限proof DAGをThree.jsで表示する。
- 三次方程式・特性方程式の3根を三角形の辺へ移す族に、親問題ごとの入力portと
  `root_multiset_to_triangle_invariant` bridgeを追加した。
- 根から構成した三角形、内接円、外接円、内心、外心を模範解答図として描く。
- 微積分では、計算核が返した区間分割と導関数符号から、増減表と関数の概形を描く既存経路を維持した。

## 固定入力実験

親A:

```tex
\text{三次方程式 }x^3-6x^2+11x-6=0\text{ の3実根の対称式を求めよ。}
```

親B:

```tex
\text{三角形の3辺から、面積と内接円・外接円の半径の関係を調べよ。}
```

外部LLMを使わず、特性根を三角形の辺とする漸化式問題を生成した。内接円半径と3傍接円半径の
積を問う問題で、答えは `1278`。29本の射を通り、厳密式と独立数値検証が一致した。

## 結果と考察

数値だけを変えた類題ではなく、代数側の根の対称式と幾何側のHeron因子・円半径恒等式を
別portとして必要とする問題を、その場で生成できた。親の一方を外すablationにも通過している。
ただし初回実装では、同じ親集合で再実行すると係数だけを変えて同じ `in_exradius_product` を
選び直した。原因は過去のobservableをセッション間で保持していなかったことだった。親ID集合を
キーに保存済みfamilyとobservableを読み、探索の初期除外集合へ入れる修正後、同じ入力から
`euler_center_distance`（外心と内心の距離）を生成し、厳密検証・保存まで完走した。

ただし一例の成功は任意の二親に対する完全性を意味しない。今後は同じUI契約のまま、未接続の
型と射を追加し、成功率、棄却率、親依存性、新規性をfrozen setで測る。

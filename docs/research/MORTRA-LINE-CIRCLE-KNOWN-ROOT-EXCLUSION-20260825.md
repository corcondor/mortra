# MORTRA 既知交点除外と厳密証明の追加実験（2026-08-25）

## 目的

HAGeoの固定89問だけを対象に、作図の意味を失ったために証明不能になっている問題を修復し、
問題ID、期待解答、外部LLM、問題固有の解法を使わずに追加正答を得られるか検証する。

## 原理

JGEXの2軌跡交点は、単なる連立方程式の任意解ではない。公式Newclidの
`reduce_intersection`は、交点候補が既存点と一致する場合、その候補を除外して残る交点を返す。
たとえば

```text
t = on_line t a m, on_circle t o a
```

では `a` 自身が直線と円の既知交点であり、作図点 `t` はもう一方の交点である。
ところがMORTRAのrelational bridgeは、計算量を抑えるため既存根の列挙を保留し、
多項式系へ `t=a` の枝も残していた。この拡大された解集合上では目標命題が成立しない場合があり、
正しい作図に対する定理でもイデアル所属を証明できない。

修正は、型付き節から既知根が直接見えるline-circle交点に限り、次を行う。

1. 既存点を2本の軌跡方程式へ厳密代入し、余りが両方0であることを確認する。
2. 出力点と既存点の平方距離を非零条件として保存する。
3. 境界方程式、代入余り、非零条件、SHA-256を局所証明書へ保存する。
4. 最終方程式 `u g = 0` の因子 `u` が保存済み非零条件から従う場合だけ、`g = 0` へ縮約する。
5. 縮約恒等式と最終Groebner証明を再生し、余り0の場合だけ認証する。

これは未知因子の除去ではなく、公式作図意味論が既に保証する正則局所化である。

## 方法

### 実装

- `worker/backend/jgex_exact_constraint_bridge.py`
  - `existing_intersection_root_exclusion` 証明書を追加
  - line-circle節の共有既知根を構造から検出
  - source-provedな非零因子だけを除く `regular_unit_contraction` を追加
- `scripts/experiment_jgex_exact_unsolved_set.py`
  - 正則因子縮約の実験フラグとartifact保存を追加
- 問題名を変えた同型構造、共有根のない負例を含む回帰試験を追加

`2024PlanetCupp10`に対し、入力、表現、飽和深さ、F5B、局所消去上限、300秒上限を固定した。

## 考察

対照では残った非零余りが、公式の分岐意味を戻した処置で0になった。
したがって `2024PlanetCupp10`については、探索深度や規則量ではなく、
**作図点の同一性をrelational表現で落としていたこと**が未証明の直接原因だった。

一方、同じ表層構造を持つ残り7問は180秒で閉じなかった。4問は正則因子を除去して
最終Groebnerまで進んでいるため、次の課題は保存済み縮約環からの消去順序または
型付き中間補題分割である。3問は作図意味の準備段階が支配的であり、式展開を避ける
構造的な座標chartが必要である。既知根除外を一般的な万能解法とは扱わない。

## 結論

公式Newclidの交点選択意味をMORTRAの厳密多項式経路へ復元し、
問題固有分岐なしで固定未認証問題を1問新たに証明した。監査済み総合値は
**60/89（67.42%）**へ上昇した。次の実験も母集団をこの89問に固定し、
今回保存した29問の停止段階から、最終環の縮小と中間補題分割を比較する。

# MORTRA 三次元包含問題の公開経路検証（2026-09-02）

## 結論

これまで公開画面で未解決だった「正四面体に含まれる最大の立方体」を、MORTRAの一問解答経路で処理できるようにした。正四面体の一辺を現在の問題文から読み取り、最大辺長を厳密な根号で返す。問題文、解答、三次元の模式図、等号を与える平行断面図、入力に結び付いた証明書も同時に生成する。

正四面体と立方体の組合せに対する大域的な最適性は、H. T. Croft が1980年に証明した定理を外部の補題として用いる。MORTRAは、その依存関係を隠さず証明書へ記録する。その上で、現在入力された一辺の長さに対する縮尺、立方体の8頂点、正四面体の4面との接触、および最終値を厳密に再計算する。

## 目的

公開画面で探索候補が0件だった三次元問題について、次の原因を区別する。

1. 問題文から立体、包含、相似比、最大化を読み取れていない。
2. 読み取れているが、三次元の包含条件を計算可能な式へ変換できない。
3. 候補配置は作れるが、すべての向きに対する上限を証明できない。
4. 解答は内部にあるが、公開用の図・解説・証明書へ渡せない。

問題固有の答えを登録するのではなく、一辺の長さと表現が変わっても同じ処理を再利用できることを成功条件とした。

## 原理

正四面体を、外向き単位法線 `n_i` をもつ四つの半空間として表す。中心 `c`、辺長 `s`、互いに直交する三方向 `u_j` をもつ立方体が入る条件は、各面について次の支持関数の不等式で表せる。

```text
n_i・c + (s/2) Σ_j |n_i・u_j| <= 内接球半径
```

四つの法線の和が0であるため、四不等式を加えると、固定した向きに対する辺長の上限が得られる。向き全体に対する最小値はCroftの定理を用いる。等号を与える向きでは、中心、8頂点、4面との接触をMORTRAが厳密に再計算する。

公刊済み定理の記録には、論文名、掲載誌、DOI、厳密値を確認できる資料、および記録全体のSHA-256を保存する。記録の一文字を変更した場合は証明書の再生を拒否する。

## 方法

公開製品と同じく、研究用の完成経路を許可しない一問解答経路を用いた。入力形式を変えた次の4問を解いた。

1. 一辺が1である正四面体
2. 「内部に収まる」という別表現で一辺が2
3. TeXの分数で一辺が `7/3`
4. 小数で一辺が `1.5`

さらに、一辺が負の問題と一辺が書かれていない問題を誤って受理しないことを確かめた。各成功例では、厳密解、現在入力用の証明書、公刊済み定理の記録、図、解説、Unicode置換文字の有無、および外部の大規模言語モデルを使用していないことを機械的に検査した。

## 結果

有効な4問は4問とも解答に成功した。不正入力2問は2問とも拒否した。合計6件中6件が期待した結果と一致した。

一辺が1の場合の最大辺長は次の値である。

```text
sqrt(6) / (sqrt(6) + 2 sqrt(2) + 3)
```

一辺が2、`7/3`、`1.5` の場合も、現在入力された一辺に比例する厳密値を返した。最終監査時の4件の有効入力に対する処理時間は、同じWindows環境で1件あたり1.33秒から1.59秒だった。これは4件だけの測定範囲であり、一般的な性能値としては扱わない。

関連する回帰試験は206件中206件が成功した。生成した日本語LaTeX文書は、upLaTeXとdvipdfmxで5ページのPDFへ変換できた。目視確認では、問題文、根号による厳密解、三次元の模式図、平行断面図に文字化けはなかった。

## 考察

以前に候補が0件だった直接の原因は、三次元の包含・相似・最大化を一つの実行可能な型付き処理へ結び付ける契約がなかったことである。今回、問題文から正四面体、立方体、一辺、包含、最大化、三次元を別々の型付き対象として取り出し、半空間の支持関数へ変換したことで、数値だけを変えた問題にも同じ処理を適用できた。

一方、大域的な向きの最適化までMORTRAが新たに証明したわけではない。そこはCroftの公刊済み定理に依存する。現在入力に対する幾何計算と、外部の大域定理を証明書内で分けたため、どこまでをMORTRA自身が再生したかを確認できる。

解説文書の検証中、画面用の固有図が一般的な証明手順図で上書きされ、PDFから消える共通不具合も見つかった。固有図と一手ずつの図解を両方残すように修正した。平面断面が三次元座標系を引き継いで歪む問題も修正した。

## 結論と次の課題

この実験により、正四面体と立方体については、表現と正の一辺の長さが変わっても、公開経路から厳密解・図・解説・証明書を生成できるようになった。これは任意の立体どうしの包含を解けることまでは意味しない。

次は、同じ半空間・支持関数・相似比の表現を、正八面体、直方体、角柱などの未登録の組合せへ適用する。大域定理がない組合せでは、区間演算または多項式最適化による上限証明を追加し、公刊済み定理への依存なしで証明書を閉じられるかを測る。

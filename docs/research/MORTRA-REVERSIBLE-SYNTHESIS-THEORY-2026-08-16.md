# MORTRAの可追跡・逆向き作問理論

## 1. 中心命題

LLMとMORTRAの本質的な差は、確率を使うかどうかではない。生成対象と
検証境界が異なる。

```text
LLM:
prompt -> text tokens -> optional mathematical validation

MORTRA:
typed mathematical goal -> morphism/proof search -> certificate
  -> natural-language rendering
```

LLMは条件付き分布

```text
p_theta(x_t | x_1, ..., x_(t-1), prompt)
```

から次トークンを生成する。内部表現が数学的抽象を全く持たない、という
主張はしない。しかし通常のデコード結果には、各文がどの数学的対象、
変換、前提、証明義務から生じたかを再実行できる証明書が付かない。

MORTRAは文章ではなく、型付き数学対象と実行可能な射の合成を生成対象と
する。文章は最後に得られた構造の表示である。

## 2. 数学的モデル

MORTRAの探索空間を型付き有向ハイパーグラフとする。

- 頂点 `X` は型付き数学状態または対象。
- 射 `f: X -> Y` は構成、変換、消去、観測、補題適用。
- 各射は前提 `Pre_f(X)` と事後条件 `Post_f(X,Y)` を持つ。
- 問題の目標は終状態上の述語 `G(Y)`。
- 証明は射の列またはDAG `T = (f_1, ..., f_n)`。

前向き実行は合成

```text
X_n = f_n o ... o f_1(X_0)
```

である。各段階で型検査、前提検査、CAS計算、証明検査を行う。

## 3. 「逆向き」の厳密な意味

MORTRAの射がすべて逆射 `f^{-1}` を持つわけではない。消去、射影、面積の
観測などは一般に情報を失う。したがって「答えから入力を一意に復元できる」
ことを可逆性とは呼ばない。

MORTRAで必要な逆向き推論は、目標から必要条件を伝播することである。射
`f: X -> Y` と目標 `G(Y)` に対し、最弱事前条件

```text
WP_f(G)(X) := G(f(X))
```

または関係の逆像を計算する。作問時は次を同時に探索する。

```text
forward frontier:  親問題から構成可能な対象
backward frontier: 目標を成立させるために必要な証明義務
meet condition:     型、制約、非退化条件が両側で一致
```

従って「遡れる」とは次の二つを指す。

1. provenance replay: 結果から使用した射と中間状態を逆順に閲覧できる。
2. backward obligation search: 目標から必要な前提・中間補題を逆向きに生成できる。

前者は監査可能性、後者は逆設計能力である。

## 4. 生成物の証明書

公開可能な問題は最低限、次の組を持つ。

```text
A = (P, IR, T, C, V, R)
```

- `P`: 人間向け問題文。
- `IR`: 型付き意味表現。
- `T`: 使用した射の列または証明DAG。
- `C`: 前提、非退化条件、消去条件。
- `V`: CAS/SMT/Lean等の検証証明書。
- `R`: 親問題、探索版、正規形ハッシュを含むprovenance。

`P`だけが存在し、`T/C/V`を再生できない生成物は、MORTRAの意味で完成した
作問ではない。

## 5. 過去問再生成との区別

LLMが既存問題に近い文章を出す危険は、単に確率的だからではない。学習
コーパスの記憶、頻出パターンへの高確率集中、出典を示さない潜在表現が
組み合わさるためである。MORTRAにも、既存の射列をそのまま再利用するだけ
なら同じ問題が起こる。

新規性は少なくとも四層で測る。

1. lexical novelty: 問題文の文字列・埋め込み類似度。
2. object novelty: 型付き対象・制約骨格の同型性。
3. path novelty: 射列・証明DAGのグラフ編集距離。
4. dependency novelty: 親を除くと同じ生成物へ到達できるか。

文字列が違うだけで構造と射列が同じなら「数値替え類題」である。文字列が
似ていても、新しい中間対象や証明DAGが必要なら構造的新規性があり得る。

## 6. 有限語彙とスケール

有限語彙は探索を有限時間で終える十分条件ではない。有限個の射でも合成長が
無制限なら経路数は指数的に増える。スケールには次が必要である。

- domain/codomainによる型不一致経路の即時除去。
- e-graphによる同値状態の統合。
- 対称性・正規形による同型候補の商。
- 前向きfrontierと後向きfrontierの双方向探索。
- CAS反例による早期棄却。
- 証明義務の難易度と新規性を含む探索コスト。

したがってMORTRAの優位性は「無限探索をすること」ではなく、型と証明義務で
探索空間を圧縮し、残った経路を再実行可能にすることにある。

## 7. 反証可能な実験条件

MORTRAが解法暗記ではなく逆向き構造探索を行う、という主張は次で検証する。

1. 点名・数値・表層文を変えても同じ型付き射が発火する。
2. 結論を偽命題へ変更すると証明書生成が失敗する。
3. 未見の親問題でも既存の問題ID分岐なしにIRへloweringできる。
4. 生成した射列を先頭から再実行して同じ結論を得る。
5. 目標から計算した後向き義務と前向き状態が同じ中間型で合流する。
6. 既存コーパス最近傍と、制約骨格・射列正規形の双方で一致しない。
7. surface-templateを除去しても成功率が維持される。

このうち5が成立しなければ、可追跡ではあっても逆向き作問器とは言えない。

## 8. 現在の到達点

現在のMORTRA exact geometry portfolioでは、19構成語彙を実行可能な多項式
制約へloweringし、証明書の独立replayによりIMO-AG-30の20/30をportfolioで
確認した。点名変更と偽結論のテストも通る。

これは `IR -> executable constraints -> exact certificate` の可追跡性を示す。
一方、一般の作問について目標から中間補題を自動合成し、前向きfrontierへ
必ず合流させる機構は未完成である。従って現時点の正確な表現は次である。

```text
確立済み: 一部の幾何語彙での型付きlowering、実行、証明書replay
未確立:   任意の親問題に対する完全な逆向き作問と新規性保証
```

## 9. 次の実験

固定した20/30を基準点とし、`research/reversible-synthesis` ブランチで次を測る。

1. 同じ親集合に対するforward-only探索。
2. backward-only義務生成。
3. bidirectional meet-in-the-middle探索。
4. 各方式の成功率、探索ノード数、時間、証明書長、新規性。
5. 親問題をheld-outへ変えたときの構造的一致率。

双方向方式が正答率または探索効率を上げ、かつ証明書・新規性条件を落とさない
場合にのみ、逆向き推論の有効性を支持する。

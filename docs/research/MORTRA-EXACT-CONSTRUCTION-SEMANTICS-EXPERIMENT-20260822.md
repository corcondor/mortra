# MORTRA 厳密作図意味論の接続実験（2026-08-22）

## 目的

固定未解決問題 `2022CHNSouthEastMOg11p6` が解けない原因を、発火数や述語頻度の
相関ではなく、公式 Newclid の作図コード、MORTRA の多項式制約、生成された証明式を
直接比較して特定する。原因にだけ介入し、LLM と期待解答を使わずに追加正答が生じるかを
認証済みベンチマークで測る。

## 仮説

Newclid が JGEX の作図時に課す「新点の選択」と「交点の非退化条件」が、MORTRA の
関係的な多項式表現に保存されていない。そのため、真の作図が選ばない代数成分が残り、
正しい定理でも消去が閉じない。

## 原理

### 公式実装が定める意味

- `newclid/jgex/to_newclid.py:323-340` は、複数の軌跡を `reduce_intersection` へ渡す。
- `newclid/jgex/geometries.py:459-484` は、既存点と一致する交点をすべて除外し、
  残った交点だけを新点として返す。
- 同ファイル `363-401` は、同心円・非交差・接する場合を通常の2交点と区別する。
- 同ファイル `442-454` は、平行な2直線を1点の交点として受理しない。

したがって、軌跡方程式を単に連立するだけでは JGEX の意味と一致しない。既存根の除外、
交点の一意性、非退化条件を、消去環の局所化条件として保存する必要がある。

### 2円の既知根除去

中心を `P,Q`、既知の共通交点を `A` とする。`w=Q-P`、`r=(-w_y,w_x)` と置くと、
もう一方の交点 `K` は

```text
t = -2 r・(A-P) / |w|^2
K = A + t r
```

で厳密に表せる。`|w|^2 != 0` と `r・(A-P) != 0` は、それぞれ同心円と接円を除く。
この式を2つの円の方程式へ戻して両方の残差が0になることを証明書に保存する。また、
`K` が全既存点と異なる条件も保存し、同じ2円から存在しない3個目の交点を作る枝を拒否する。

## 実装方法

`worker/backend/jgex_exact_constraint_bridge.py` に次を接続した。

1. 複数軌跡の共通既存根を検出し、非一致条件として消去へ渡す。
2. 2本の線形軌跡から Cramer 行列式を作り、非零条件として保存する。
3. 座標を局所消去した後、非退化条件にも同じ代入を適用する。
4. 係数に有理式が残る局所消去では `EX`、純多項式では `QQ` を使い分ける。
5. 共通既知根を持つ2円について上の閉形式を適用し、再生可能な構造補題を作る。
6. 候補交点が別の既存点と恒等的に一致する場合は、作図不能として拒否する。
7. 厳密JSON証明の専用監査器を追加し、ファイルハッシュだけでなく、余り、局所補題、
   構造補題、合成証明を再検査する。

問題名、年度、期待する答え、数値定数による分岐は追加していない。

## 考察

以前の `ar-sin` 量、規則発火数、点被覆率の分析は、閉包の状態を記述していたが、作図器が
どの交点を選ぶかを検査していなかった。したがって相関は見えても、固定問題への因果介入に
ならなかった。今回は公式コードの分岐を多項式意味へ写し、同じ固定問題で介入前後を比較した。
追加正答が厳密証明書と同時に発生したため、少なくともこの1問について原因は作図意味論の
未接続だったと判断できる。

この結果は、MORTRA が任意の未知幾何を理解したことを意味しない。むしろ、複数エンジンを
接続するときは述語名の対応だけでなく、点の生成順序、根の選択、非退化条件まで含む操作的
意味論が必要だと示した。

## 結論

今回の停滞は探索深度不足だけでも、語彙数不足だけでもなかった。Newclid の作図意味を
MORTRA の厳密制約へ完全に運べていないことが、固定未解決1問の直接原因だった。意味論を
接続すると、期待解答なしで新しい厳密証明が得られ、認証済み集合は54/89へ増えた。

次の研究では、同じ手順で line-circle、一般 circle-circle、接線、円周上点の選択について
公式の操作的意味を証明条件へ写し、固定未解決集合で追加正答の有無を一構造ずつ測る。

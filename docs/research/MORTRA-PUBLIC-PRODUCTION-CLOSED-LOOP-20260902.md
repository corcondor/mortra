# MORTRA 公開版の直接検証（2026-09-02）

## 結論

`https://mortra.ai/ja` の公開画面に問題を直接入力して検証した。検証した単独問題5系統、融合問題1系統、実行不可能性の証明1件は、問題文、厳密な解答、証明過程、図を公開画面へ表示できた。日本語と TeX の文字化けは確認されなかった。

一方、未登録の幾何定理1件は解けていない。公開画面から長時間探索へ引き渡し、保存した探索状態から3ラウンドまで継続できたが、自然文を幾何関係へ変換する処理が不十分で、厳密な幾何証明器へ入力できなかった。したがって、現時点で「任意の問題を解ける」とは判定しない。

## 目的

内部関数の単体試験ではなく、利用者と同じ公開画面から次の一連の処理を検証する。

1. 日本語と TeX を入力する。
2. MORTRA が問題の構造を認識する。
3. 単独問題を解く、または複数問題から融合問題を生成する。
4. 問題文、解答、証明過程、図を表示する。
5. 即時に解けない問題を長時間探索へ引き渡す。
6. 画面を閉じても、保存した探索状態から再開する。

## 方法

- 対象: `https://mortra.ai/ja`
- 操作: 実ブラウザーから公開画面へ入力し、公開 API の応答、画面内の文字、図、通信結果、ブラウザーのエラーを記録した。
- 数学生成: 外部の大規模言語モデルを利用しない MORTRA の厳密実行経路を使用した。
- 文字表示: Unicode の置換文字 `�` と未処理の `\text` が画面に残っていないか数えた。
- 図: デスクトップ画面と携帯画面で、図の要素数、遷移数、横方向のはみ出しを調べた。
- 長時間探索: 公開 API の保存状態と GitHub Actions の実行記録を照合した。

## 長時間探索

対象問題は「鋭角三角形の垂心を各辺に関して対称移動した点が外接円上にあることを証明し、補助線を含む図を描け」である。

- 最初のジョブ: `9ab202e4-7b91-476e-bac7-05eb3c304c92`
- 1回目: 深さ4、805状態、実行可能候補148件、保存した未解決候補41件
- 2回目の後続ジョブ: `79269387-550c-4f7d-ba5b-db4137fe6ab8`
- 2回目: 深さ7、1,217状態、実行可能候補220件、保存した未解決候補48件
- 3回目の後続ジョブ: `ca26ae6c-2ee9-4594-ad61-2e607001161b`
- 3回目: 深さ10、2,445状態、実行可能候補436件、保存した未解決候補48件
- 生成済みの厳密な解答: 0件

1回目の実行記録は [GitHub Actions 33577650766](https://github.com/corcondor/mortra/actions/runs/33577650766) である。保存状態から再開した2回目は [GitHub Actions 33577954791](https://github.com/corcondor/mortra/actions/runs/33577954791) である。3回目は [GitHub Actions 33578252824](https://github.com/corcondor/mortra/actions/runs/33578252824) である。三つのワーカーはすべて正常終了した。

未解決の直接原因は、問題文中の `H`、`BC`、`CA`、`AB` と「辺に関する対称移動」「外接円上」を、点、直線、鏡映、共円という実行可能な幾何関係へ変換できなかったことである。型名だけの `PointConfiguration` は作られたが、厳密な幾何証明器へ渡せる関係と制約が作られなかった。

## 今回修正した不具合

1. TeX の空白命令 `\,` を含む入力が壊れる問題を修正した。
2. 融合問題の負の係数が `+ -` と表示される問題を修正した。
3. 状態遷移図で複数の遷移が一つに上書きされる問題を修正した。
4. Cauchy--Schwarz の不等式に反する入力を「未知」として長時間探索へ送る問題を修正し、「存在しない」という厳密な解答を返すようにした。

対応するコミットは `46e4366`、`5f93144`、`fcbe60b`、`05afc94` である。公開経路の Python 試験100件と公開ワーカーの試験191件はすべて成功した。

## 未検証範囲

公開画面には画像または PDF を選ぶ入力欄が存在しない。そのため、画像から問題文を読み取る光学文字認識は今回の公開版では試験できない。今回確認した「文字認識」は、日本語と TeX の文字列入力を数学構造として認識し、文字化けなく再表示する範囲である。

## 結論

公開版 MORTRA は、今回選んだ関数解析、微分、座標幾何、確率、漸化式の単独問題と、二次形式と期待値の融合問題について、問題文、解答、証明過程、図を一つの公開画面で返した。実行不可能な条件も、未解決扱いではなく数学的に否定できた。

未登録の自然文幾何では、長時間探索の保存と再開は機能したが、幾何関係への変換が未完成である。次の改善対象は探索時間ではなく、「垂心」「辺に関する鏡映」「外接円上」という語を、既存の幾何述語と作図操作へ正確に変換する処理である。

# MORTRA 公開版の直接検証（2026-09-02）

## 結論

`https://mortra.ai/ja` の公開画面に問題を直接入力して検証した。検証した単独問題、融合問題、実行不可能性の証明は、問題文、厳密な解答、証明過程、図を公開画面へ表示できた。日本語と TeX の文字化けは確認されなかった。

初回検証で未解決だった垂心の鏡映と外接円の問題は、自然文幾何の型付き変換と厳密な座標証明を追加した後、公開版で解決した。三角形の頂点名と垂心名を変更し、「対称移動」を「折り返す」へ言い換えた入力でも同じ実行経路が成立した。ただし、公開画面には画像入力がないため画像 OCR は未検証であり、「任意の問題を解ける」とは判定しない。

## 追試: commit `70ef46b`

初回検証後、自然文から次の型付き関係を構成する有限 elaborator を追加した。

- 三角形と三頂点
- 垂心と三本の垂線
- 点の直線に関する鏡映
- 三つの鏡映点の外接円への所属

証明は問題固有の座標値を保存せず、任意の一辺を `B=(0,0)`, `C=(1,0)`、対頂点を `A=(u,v)` と正規化する。垂心を `H=(u,h)` とすれば `h=u(1-u)/v` であり、辺 `BC` に関する鏡映点 `(u,-h)` を外接円

\[
x^2+y^2-x+(h-v)y=0
\]

へ代入した残差は `u^2-u+vh=0` へ還元される。辺の選択は任意なので三辺すべてに適用できる。公開画面は三角形、垂線と垂心、三つの鏡映、外接円という4段の図を同じ証明状態から生成した。

## 目的

内部関数の単体試験ではなく、利用者と同じ公開画面から次の一連の処理を検証する。

1. 日本語と TeX を入力する。
2. MORTRA が問題の構造を認識する。
3. 単独問題を解く、または複数問題から融合問題を生成する。
4. 問題文、解答、証明過程、図を表示する。
5. 即時に解けない問題を長時間探索へ引き渡す。
6. 画面を閉じても、保存した探索状態から再開する。

## 方法

- 対象: `https://mortra.ai/ja`
- 操作: 実ブラウザーから公開画面へ入力し、公開 API の応答、画面内の文字、図、通信結果、ブラウザーのエラーを記録した。
- 数学生成: 外部の大規模言語モデルを利用しない MORTRA の厳密実行経路を使用した。
- 文字表示: Unicode の置換文字 `�` と未処理の `\text` が画面に残っていないか数えた。
- 図: デスクトップ画面と携帯画面で、図の要素数、遷移数、横方向のはみ出しを調べた。
- 長時間探索: 公開 API の保存状態と GitHub Actions の実行記録を照合した。

## 結論

公開版 MORTRA は、今回選んだ代数、微積、座標幾何、確率、有理角の整数問題と、二次形式と期待値の融合問題について、問題文、解答、証明過程、図を一つの公開画面で返した。実行不可能な条件も、未解決扱いではなく数学的に否定できた。

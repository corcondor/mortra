## 目的

最終 Groebner 計算まで到達した未判定义務を、述語の意味に沿う小さな中間命題へ分割し、
各証明書の合成として閉じられるかを測る。同時に、8月21日以降の急激なスコア上昇が
実能力によるものか、採点条件による見かけの上昇かを、全増分artifactを遡って監査する。

## 原理

### 型付き目標分割

例えば `midp M A B` は座標上で

```text
2 M_x - A_x - B_x = 0
2 M_y - A_y - B_y = 0
```

という2つの型付き中間命題へ分けられる。元の目標多項式が両成分の平方和なら、各成分の
Groebner証明書を再生し、重み付き平方和として再合成できる。このとき「余り0」だけでなく、
各成分と最終合成の恒等式を別々に確認する。

### 非空性と単位イデアル証明

Groebner基底が `[1]` なら、その計算で使った環と符号化の上では作図方程式のイデアルが
単位イデアルであり、任意の目標の余りが0になる。SHA-256は証明書の完全性を保証するが、
意図した幾何配置の非空性は保証しない。独立した非空性証明が無い限り、幾何命題の正答には
数えられない。これは元の数学的結論が偽だという判定ではなく、このartifactだけでは結論を
認証できないという判定である。

ただし局所表現で一部座標を係数体へ移すと、整合的な構成でも局所化された環で `[1]` が出る。
そのため `[1]` が出た場合は、全残存記号を変数へ戻した多項式環で再計算し、それでも単位
イデアルとなる場合は、独立した非空性証明が得られるまで未認証として除外する。

### 人間が読める解答

機械証明書とは別に文章を生成すると、証明と説明が食い違う。そこで解答は次の証明書項目から
決定論的に投影する。

1. 座標規格化
2. 作図語彙と多項式制約
3. 再生済み局所補題・構造補題
4. 型付き中間命題
5. `M G = sum(q_i g_i) + r` の最終恒等式
6. `r=0` と非空性監査に基づく結論

完全な式は機械検証用付録へ置き、本文では幾何条件と証明段階を表示する。

## 継続実験: 除外6問の構成意味論からの再求解

### 目的

逐次Groebner消去で停止した6問について、問題ごとの数値や点名を分岐条件にせず、JGEXの
構成依存関係を一般的な座標チャートへ写し、結論までの恒等式・図・停止中のNewclid閉包を
同一成果物へ残す。特に、`[1]` を使わず、元の構成が存在する有理関数体上で各点を順に作る。

### 方法

三角形の内接円を単位円、内心を原点、辺 $BC$ を $y=-1$ とし、残る2辺を接線パラメータ
$p,q$ で表した。直線と円の第2交点、外心、2円の第2交点、直線交点だけを共通演算として
用いた。2016年とPlanet Cupは外接円を固定した2変数座標、USAMOは重心座標を用いた。

XinXing問題では通常のSymPy式木による消去が14分間進まなかった。同じ演算を
$\mathbf{Q}(p,q)$ の多変数有理関数体へ移すと、座標を常に既約分数として保持でき、32恒等式を
約2秒で再生できた。近似や乱択へ落とした高速化ではない。

## 条件付き証明の再監査 v24

### 訂正

v22では、一般位置を仮定した座標恒等式がすべて0になったことを「厳密再生」と記録した。
しかし、これは元の構成から分母の非零性と交点分岐まで導いた完全証明とは異なる。
判定器を修正し、未消去条件が残るチャートは `conditional`、構成領域まで閉じたチャートだけを
`proved` とするよう変更した。

### 方法

Newclid公式実装の構成意味論を直接監査した。

- 直線は相異なる2点を要求し、平行2直線の交点を拒否する。
- 外心は非共線な3点を要求する。
- 円交点は同心円・実交点なしを拒否する。
- `reduce_intersection` は既存点と一致する交点を拒否し、既知共有点がある場合は第2交点を選ぶ。

各座標式の分母をこれらの構成に対応させ、問題IDや数値例ではなく、作図DAGの成功条件から
非零性を消去した。

|---|---:|---:|---|
| `2005CTSTp19` | 16 | 0 | proved |
| `2016USATSTSTp2` | 24 | 2 | conditional |
| `2017CHNGaoLian` | 19 | 0 | proved |
| `2021GOWACAp3` | 24 | 0 | proved |
| `2023PlanetCupp9` | 21 | 0 | proved |
| `2023SerbiaMOp6` | 19 | 0 | proved |

2016年問題では、チャートが直線 `NP` 上の共通点を1つ構成する一方、形式入力のTは既知共有点を
持たない2円のどちらの交点でもよい。2円の接触判別式は一般に

```text
-(u^4-6u^2v^2-2u^2+v^4+6v^2+1)^2
 / (16u^2v^2(u^2-v^2-1)^2)
```

で0ではない。したがってTの分岐は構文から固定できず、`K(u,v) != 0` と「TがNP上の根を表す」
条件を保留した。これは証明探索の失敗ではなく、現在の形式問題が結論に必要な分岐を指定して
いないことによる。

### 結論

除外8問のうち7問は、非退化条件と第2交点分岐まで含む再生可能証明へ昇格した。1問は曖昧な
入力を理由に条件付きのまま残した。これらは対象確認後の修復結果なので、凍結89問の得点へは
遡及加算せず、厳格認証下限を `59/89` に維持する。証明書・日本語証明・図は
`artifacts/reverify-unit8-continuation-v24/` に保存した。

## 存在交点の量化修復と8問完全監査 v25

### 目的

v24で残った `2016USATSTSTp2` の2条件を、分岐を恣意的に固定せず消去する。特に、自然文の
「2円が直線PN上で交わる」という存在命題と、一出力JGEX節の交点選択を区別し、誤形式化を
証明済みとして扱わない。

### 方法

`typed_existential_incidence` を実装し、証人点を含む全incidenceと目標の残差が揃った場合だけ
`exists T` 証明書を発行するようにした。2016年問題では、`T=N+z_T(P-N)` を2円の共有一次因子
から合成し、`T` の2円への所属と `P,N,T` の共線を別々に再生した。

また `A=u^2>0, B=v^2>0` と置き、残存分母を

```text
K = A B^2 + 2(A-1)(A-2)B + A(A-1)^2
```

へ変形した。`0<A<1`, `A=1`, `A>1` の3枝でそれぞれ正値を証明し、最後の有限性条件を消去した。

元の一出力形式化が自然文と同値でないことも、`u=1/3, v=6/5` の厳密モデルで確認した。2円上の
もう一方の交点は `det(P,T_other)=-300249/383720` となり、`PN` 上にない。したがって任意分岐版
を正答扱いせず、自然文だけを存在量化へ修復する。

|---|---:|---:|---|
| `2005CTSTp19` | 16 | 0 | proved |
| `2016USATSTSTp2` | 26 | 0 | proved（存在命題） |
| `2017CHNGaoLian` | 19 | 0 | proved |
| `2021GOWACAp3` | 24 | 0 | proved |

| `XinXingV28p2` | 32 | 0 | proved |

8問全てでJSON、証明Markdown、SVGを再生成し、未消去条件は0となった。2016年問題の証明書は
自然文の存在命題を認証する一方、`arbitrary_source_branch_proved=false` と量化反例を保持する。

### 考察

v24の保留は探索不足ではなく、存在量化を任意交点の一出力構文へ落としたことが原因だった。
交点候補を目標に合うよう後付け選択するだけでは循環になる。今回は直線上の有理関数証人を先に
合成し、その後に2円制約を独立再生したため、目標のコピーではない。

この修復は、円円交点に限らず、多値の根・交点・場合分けを一出力構文へ落とす全問題に適用できる。
一方、元データの量化誤りを修正しているため、HAGeo入力をそのまま解いた得点としては扱えない。

### 結論

除外8問の数学的定理について、構成領域・分岐・存在証人まで含む再生可能証明を得た。7問は元入力
と同値、2016年問題は公式自然文の存在命題へ量化修復した。成果物は
`artifacts/reverify-unit8-continuation-v25/` に保存した。全件が後知恵チャートであり、2016年には
形式化修復もあるため、凍結認証下限は **59/89** のままとする。

### 再発防止

問題固有の固定フラグでは不十分なため、JGEXの一出力交点節を関係型から監査する
`audit_jgex_multivalued_intersections` を実装した。円円交点と直線円交点には自動で分岐証明義務を
付け、一意性、明示的分岐選択、または型付き存在証人のいずれも無い場合は元入力を厳格認証しない。
問題名・数値・期待解答には依存しない。単一値構成を誤検出しない試験と、改名した交点構文を検出
する試験を追加した。分岐監査の対象18件を含む全関連回帰試験56件が成功した。

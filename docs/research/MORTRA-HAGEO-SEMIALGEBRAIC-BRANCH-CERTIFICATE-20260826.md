# MORTRA 半代数的枝証明書によるHAGeo追加認証

## 目的

HAGeo固定89問で未認証だった `2014CHNGaoLian` について、自然文からJGEXへ変換すると失われる半平面条件を、目標や問題IDに依存しない共通機構として復元する。さらに、この機構が残りの問題へどこまで再利用できるかを固定89問全体で監査する。

## 仮説

この問題の停止原因は探索深度ではなく、接線と円の交点が持つ二つの代数的な枝のうち、原文が指定する枝を形式化できていないことである。`same_side` と `opposite_side` を符号条件として保持し、枝選択を独立した証明書として再生できれば、既存の厳密消去器で結論まで閉じられると予想した。

## 原理

外心を `O`、基準辺を `BC` とする。`D` は `B` における外接円の接線上にあり `BD=BC`、`E` は `C` における接線上にあり `CE=CB` とする。

`R=C-B`、`q=O-B`、`u=D-B`、`v=E-C` とおく。外心、接線、等長条件は

```text
2 q.R = |R|^2
u.q = 0,       |u|^2 = |R|^2
v.(q-R) = 0,   |v|^2 = |R|^2
```

である。二次元では、これらから `v` は `u` を `BC` の垂直二等分線方向へ反射したベクトル `S(u)`、またはその反対 `-S(u)` のどちらかになる。原文の `D,E` が `BC` の同じ側にあるという厳密符号条件

```text
cross(C-B,D-B) * cross(C-B,E-C) > 0
```

は `-S(u)` の枝と矛盾する。したがって `v=S(u)` が一意に残る。これは等式イデアルだけでは表せないため、代数的な二枝の分解と符号による棄却を一つの半代数的証明書として保存する。

## 実装方法

1. HAGeo-409の自然文を問題IDで対応づけた意味sidecarを生成した。
2. 英文の `same side`、`opposite sides`、`one side ... other side` を字句・構文解析し、型付き半平面関係へ変換した。
3. 同一の外心に対する対称な `on_tline + on_circle` 作図を、目標を見ずに作図型だけから検出した。
4. 共通の基準点と反対側にある2点は同じ側にある、という有限符号推論を実装した。
5. 枝積の多項式恒等式、棄却枝の符号矛盾、座標置換をSHA-256付き証明書へ保存した。
6. 選択枝で変数を消去した後も、元の作図式、非退化条件、局所補題、最終余りを再生した。

問題名、期待解答、目標述語による分岐は追加していない。

## 結果

### 対照実験

同じ対称接線作図に対して、選択枝が直接含意する `DE parallel BC` を目標にした。

| 入力意味条件 | 枝証明書 | 厳密証明 |
|---|---:|---:|
| 原文どおりの同じ側 | 1 | 成功 |
| 半平面条件なし | 0 | 不成功 |
| DとEが反対側になる矛盾条件 | 0 | 不成功 |

したがって、構造を見つけただけで答えを強制してはいない。原文の意味条件が証明できる場合だけ枝を選ぶ。

### 固定問題

`2014CHNGaoLian` は独立プロセスで60.74秒、`remainder=0`、`exact_replay=true` となった。半代数的枝証明書は1件で、`goal_independent=true`、恒等式再生も成功した。期待解答と外部LLMは使用していない。

固定89問の監査済み集合和は次のように更新された。

```text
63/89 = 70.79%
64/89 = 71.91%
増分   = 1問、+1.12 percentage points
```

初期の40/89からは64/89となり、認証問題数は24問増加、正答率は約26.97ポイント上昇した。

### 適用範囲監査

固定89問すべてを問題ID・目標非依存で監査した結果、この特定の「対称接線・等半径・同じ側反射」定理が発火する問題は `2014CHNGaoLian` の1問だけだった。したがって今回の追加正答は再現可能だが、この一つの定理を残り25問へ横流しして得点を増やすことはできない。

## 考察

性能上昇は実在する。一方、残り25問が全く違う種類の数学へ移ったわけではない。追加前の監査では、未認証26問の目標述語は全て認証済み側にも存在し、作図語彙23種中22種も共通していた。差は作図節数の中央値が8から13.5へ増え、円・外心・交点の連鎖と枝条件が長くなったことである。

今回の実験は、残りのhard tailに少なくとも二種類の原因があることを実証した。

1. 自然文の側・順序・内外・第二交点などが形式入力から落ち、等式だけでは反例枝を含む。
2. 入力は十分でも、円・外心を含む長いproof DAGを型付き中間補題へ縮約できない。

前者は探索時間を増やしても解けない。後者は意味条件を追加するだけでは解けない。停止原因を先に分類し、対応する共通射だけを実装する必要がある。

## 結論

不足は新分野の語彙そのものより、自然文の半代数的意味を作図へ結び戻すことと、長い円・外心DAGを小さな証明書へ分解することにある。今回、前者の一族を一般化して1問を追加認証し、総合値を64/89へ上げた。

次の優先順位は、`between`、`inside`、`ray`、`second_intersection`、角の大小を同じ型付き意味IRへ追加し、それぞれについて目標非依存の対照実験を行うこと、その後に残る長い円・外心DAGの局所補題合成へ戻ることである。

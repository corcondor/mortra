## 3. C-RASP 論文が与える視点

**Algebraic Decomposition Theory for Transformer Length Generalization**
Yang, Veseli, Barloy, Cadilhac, Krebs, Paperman, Straubing, Hahn
<https://arxiv.org/abs/2608.13433>

### 3.1 二重の表現不能（ここが重要）

論文が Krohn-Rhodes を退ける理由は「K-Rが弱い」ではない。**双方向に表現不能**である。

```
K-R の原子（flip-flop・単純群）  →  C-RASP では表現できない
C-RASP の原子（非有界カウント）  →  K-R の有限半群では表現できない
```

どちらの原子集合も他方を含まない。だから**合成をいくら重ねても届かない**。
探索の深さの問題ではなく、原子集合の選択の問題である。

### 3.2 何をしたか

有限半群の古典的分解理論を、**整数の無限加法群**へ一般化した。
道具は**整数の反復リース積**と、Krebs 2008 の**型付きモノイド**。

そこから、**正規言語が C-RASP に属するかの多項式時間判定手続き**を導いた。
多項式は**構文モノイドの大きさ**についての多項式である。
Tilson 1987 の Derived Category Theorem が、あるモノイドを別のモノイドで
「割る」操作を与える。

結果として、**任意の正規言語について、transformer が長さ一般化するかを
事前に判定できる**。100以上の正規言語で理論の予測が当たった。

### 3.3 MORTRA との対応

構造が一致している。

| C-RASP | MORTRA |
|---|---|
| 原子 = 非有界カウント | 原子 = DD規則 + 構成演算子（`on_tline`, `intersection_pp`, `reflect`, …） |
| 合成 = リース積 | 合成 = 前向き閉包 `forwardChain` |
| 到達可能性 = 言語が C-RASP に属するか | 到達可能性 = 目標述語が閉包に入るか |
| 判定手続き = 多項式時間 | **判定していない。3,328試行で経験的に発見している** |

**MORTRA は、判定できるはずの問いを、探索で答えようとしている。**

3.8時間かけて「到達不能」を発見している。46問について、
それが探索の失敗なのか原理的な未到達なのかを、区別していない。

### 3.4 なぜ chart を作っても通らなかったか（1.3 の説明）

表現Atlas は、`lequation/perp` を計量chart（内積・二次形式）へ、
incidence/affine をアフィンchart（行列式・rank）へ移す。

だが 3.1 が言っているのは、**別の chart へ移しても、その chart の原子が
目標を生成しないなら届かない**ということである。chart 間の橋は
「完成した証明書」を運ぶ。**未完成の義務を、別の原子集合で生成し直す
経路になっていない。**

だから健全性は上がり（構成エラー 7→0、静的反証 2,395件）、
到達可能性は1ミリも動かなかった（chart経由候補 0、追加正答 0/3）。

### 3.5 代数の型も合っている

C-RASP の核が非有界カウントで、自然な代数が (ℤ,+) であること。
MORTRA の AR 層は**実際に線形**である。

```json
"ar_residual_support": 2, "ar_residual_l1": 2.0, "ar_known_rank": 39
```

`ar_known_rank` は線形系の階数そのもの。**MORTRA の AR 層は
C-RASP の計数核と同じ代数的性格を持つ。**

そして Krebs の「型付き」モノイドについて、MORTRA は既に全面的に型付きである
（`Point2/Point3`、`Line2/Line3`、`Plane3`、`Circle2`、`Sphere3`、型付き義務）。
**型付きモノイドの枠組みは、MORTRA にとって飛躍ではない。**

## 5. 次にやること

### 5.1 到達可能性の事前判定（本命）

探索の前に、目標述語が現在の原子集合の閉包に入りうるかを判定する。

1. `yuclid_native_verifier` が `payload` に持っている `all_deductions` の
   **述語名と引数sortの多重集合**を記録する。現在は件数しか残していない。
2. 目標述語から後ろ向きに1〜2段展開し、必要な述語集合を出す。
3. 前向きが産む集合と、後ろ向きが要求する集合の**差集合**を取る。
4. 差集合が空でなければ、**その問題は現在の原子では到達不能**であり、
   差集合の要素が「足りない原子の名前」になる。

閉包が小さい問題から始める。早く飽和する＝差が読みやすい。


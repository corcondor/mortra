# MORTRA 入力忠実性・公開UI閉ループ検証（2026-09-02）

## 目的

`mortra.ai` に一問または二問を直接入力したとき、入力を別問題へ置き換えず、MORTRA自身の厳密計算で問題文・解答・説明・図・証明書を公開UIへ返せるかを確かめる。直ちに閉じない問題については誤答を公開せず、永続研究キューへ移し、再読み込み後も同じ探索へ戻れることを確認する。

## 仮説

問題28が公開経路で未解決になった原因は解法の不足ではなく、名前を付けない積分式と、TeX数式を閉じる `$` を上界証明の入力形式として認識できていないことにある。この仮説が正しければ、入力形式の一般的な正規化だけで問題28が新たに認証され、固定90問中の他89問の判定は変化しない。

## 方法

1. `全問題.tex` 由来の固定90問を、期待解答なし、外部LLMなし、独立再生可能な証明書必須の条件で測定した。
2. 名前付き積分 `I=...` と、問題文のままの `\int...<2 を示せ` を同じ型付き積分義務へ変換した。
3. 被積分関数、積分区間、要求された上界を入力から読み直し、異なる被積分関数や上界 `<3` には同じ証明を流用できない回帰試験を置いた。
4. Vercel本番配置後、`https://mortra.ai/ja` の実際の入力欄をPlaywrightで操作した。390 x 844 と 1440 x 1000 の画面で、入力往復、API経路、問題文、解答、解説、証明書、図、横方向のはみ出し、文字化け、再読み込み後の再接続を検査した。

実装コミットは `09b7757` である。

判定が変化したのは問題28だけだった。問題28は `synthesized_proof_program` として認証され、証明プログラムは補角、`sin t<t`、Cauchy--Schwarz、不等式の有理数比較を現在の入力から再生する。他89問の認証結果と解答は変化していない。

### 公開UI、スマートフォン幅

固定した8件を全件実行し、8/8件が期待した挙動になった。

- 7/8件: その場で厳密解答を生成
- 1/8件: 未対応のディリクレ級数を誤答せず永続研究キューへ移送
- 解決7/7件: 問題文、解答、解説、再生可能な証明書、少なくとも1個の図を表示
- 入力往復: 8/8件で日本語・TeXが入力値と一致
- 文字化け、置換文字、`undefined`、生のLaTeX表示: 0/8件
- 横方向のページはみ出し: 0/8件
- 予期しないブラウザエラー: 0/8件
- キュー移送した1/1件: 再読み込み後に同じ仕事へ再接続

実行対象は、連立方程式、二階漸化式の母関数、三次関数の増減表と概形、連続する表の待ち時間と状態遷移図、三次曲線上の正三角形の重心軌跡、二次形式と期待値の二問融合、問題28の積分不等式、未対応の漸化式ディリクレ級数である。

### 公開UI、デスクトップ幅

図と数式が長い重点4件を再実行し、4/4件が合格した。対象は関数の増減表・概形、確率の状態遷移図、二次形式と期待値の融合、問題28である。4/4件に解答、解説、証明書、図があり、文字化けと横方向のはみ出しは0件だった。

### 複数親問題の生成

同じ公開経路の基礎となる固定試験では、型付き二問融合30/30カードと、有限写像・軌道系10/10ケースが合格した。後者は9個の異なる実行時プログラムを生成し、残り1件は片方の親を除くと成立しないことを確認する負の対照である。登録済み完成問題の再生は0件だった。

### 画像認識

公開DOMとソースコードを調べた結果、`input[type=file]`、画像を受け付ける入力、PDF・画像アップロード操作はいずれも0件だった。したがって、今回確認できたのは日本語・TeXの直接入力であり、画像やPDFのOCRは未実装である。OCRが成功したとは扱わない。

## 考察

修正前は、同じ積分でも `I=...` と名前を付けた形だけが証明核へ届き、元の問題文にある `<2$ を示せ` はTeX閉じ記号のため拒否されていた。数学的能力が消えたのではなく、公開入力と実行可能義務の間で指示対象が正規化されていなかった。入力形式を一つの型付き義務へまとめた結果、固定母集団で問題28だけが増えたため、今回の1問増加には因果的な説明がある。

一方、19/90という固定一問ベンチマークは任意問題の完成を意味しない。公開UIで7件が解けた事実と、画像OCRが存在しない事実、71件の固定未解決を分けて扱う必要がある。未解決問題を赤字だけで終わらせず永続キューへ渡す経路は動作したが、キューが最終証明へ到達する能力は別に継続測定する。

## 結論

日本語・TeXで入力する一問解答、図解、二問融合、厳密証明書の公開表示は、今回の8件では再現した。問題28は入力形式の修正により固定90問でも新規に認証された。画像・PDFの文字認識はまだ公開機能ではない。次の実装対象は、残る未解決義務の共通構造を増やすことと、画像を同じ型付き意味IRへ入れる非LLMの入力経路である。

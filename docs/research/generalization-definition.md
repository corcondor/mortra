# 汎化の定義（MORTRA）

正答率が上がったことを汎化と呼ばない。段階で分ける。
各成分がどの段にいるかを、実行した測定に紐づけて書く。

## 段階

| | 定義 |
|---|---|
| **G0** | 固定例。特定の問題・特定の数値でだけ動く |
| **G1** | 数値・パラメータ汎化。同じ構造で係数が変わっても動く |
| **G2** | 表層汎化。変数名・語順・日本語・TeX が変わっても同じ IR に落ちる |
| **G3** | 構造汎化。未見問題を既知の制約・演算子グラフに落とせる |
| **G4** | 合成汎化。既知の演算子の未見の組合せを経路として構成できる |
| **G5** | 表現汎化。式・証明・図・3D・文章のあいだで意味の同一性が保たれる |
| **G6** | 分野横断汎化。格子 → 結晶 → 双対 → 群 → Lie → 整数論 のような経路を意味を保って構成できる |

## 汎化と認めない条件（§6.1）

次を使ったものは汎化ではない。

- 問題ID / 大学名 / 年度 / 期待解
- family_id の許可リスト
- 特定数値のハードコード
- 特定問題専用の正規表現
- 問題別のアダプタ

数学的に一般な分岐は許容する。

## 必須の検査

**metamorphic** 意味を変えない変換で答えが対応して保たれるか。
**counterfactual** 意味を変える小さな変更で答えが変わるか。

片方だけ通るものは汎化していない。前者だけなら入力を見ていない。後者だけなら表層に張り付いている。

実装は `scripts/generalization_harness.py`（CAS・幾何）と `scripts/lattice-properties.mts`（格子）。

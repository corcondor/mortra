# MORTRA-1 実行可能制約への接続実験

## 原理

問題文の分野名だけを判定しても解答にはならない。MORTRA-1では、問題文を型付き対象と射に変換し、その終点が厳密計算または有限な証明義務になる場合だけ答えを返す。

今回追加したのは、問題番号や既知の答えを参照する規則ではなく、次の再利用可能な射である。

1. LaTeXの極限・積分・閉命題を、束縛変数を保ったSymPy演算へ変換する。
2. 等比数列の定義を代数制約へ変換し、三角恒等式とともに消去する。
3. 自己相似な無限根号を反復写像へ変換し、固定点の有無で収束を判定する。
4. 三次曲線上の正三角形を三次フーリエ成分へ変換し、重心軌跡を消去・積分する。
5. 正規化内積を二次元の正規直交基底上の回転へ変換し、関数の組を構成する。
6. Prime型を偶奇分解・整数集合への包含・平方剰余へ変換する。

## 方法

- 対象: `全問題.tex` の85入力。既存解答節はソルバー入力から除外した。
- 設定: 外部LLM、ウェブ検索、旧問題専用adapterを使用しない。
- 判定: 問題全体の答えが得られ、実行結果と検証器がともに成功した場合だけ `verified_answer` とする。
- 安全策: 複数小問の一部分だけを解いた結果、自由変数が残る式、未評価の積分・極限、元のLaTeXから依存変数が脱落した式は棄却する。
- 時間: 1問8秒で打ち切り、時間切れを正答に含めない。

## 解法暗記の検査

- 極限は変数名と係数を変えた未見式でも同じLaTeX演算木から計算する。
- 三次曲線の軌跡は曲線を平行移動しても面積が不変になることを再計算した。
- 等比数列は数列名ではなく `middle^2=first*last` を生成する。
- 内積問題は目標角を `pi/6` から `pi/3` に変え、別の関数を自動構成して積分検証した。
- 素数級数は目標上界を強くしすぎると証明を停止する反例テストを入れた。
- 素数辺三角形は、辺に2が0,1,2,3本含まれる全分岐を個別に閉じる。

全174回帰テストが成功した。途中でLaTeX `2^{\sqrt2}` を `2` と誤読していた実装を発見し、その暫定正答は破棄した。波括弧を補った後の式 `2**sqrt(2)<E` に対し、対数級数の有理上界証明を生成するよう修正した。

## 考察

改善前の主因は構文解析そのものではなく、型付きIRから実行可能な制約への射がないことだった。今回の8問増加は、この接続を追加すると実際の正答率が上がることを示す。一方、残る73問のうち59問は依然として実行器未接続であり、整数最適化、領域・通過領域、複数段の漸化式、確率分布、解析的不等式が大きい。

また、当初の緩い判定では12問を正答と数えたが、添字付き未知列や未定義記号を定数と誤認していた。これは誤答なので、依存変数・自由記号・未評価演算の検査を加え、最終値を10問に固定した。正答率を上げる際も、この棄却精度を下げてはならない。

## 結論

未検証だった問題の一部は、IRを実行可能な制約へ接続することで厳密に解けるようになった。現在値は10/85であり、全問題を解ける段階ではない。次の優先順位は、残る未接続59問を構造でクラスタ化し、最も多く再利用される `有限和・漸化式・整数条件・領域積分` の射を追加することである。

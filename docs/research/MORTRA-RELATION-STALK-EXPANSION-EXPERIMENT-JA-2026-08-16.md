# MORTRA 関係型 stalk 拡張実験

## 原理

MORTRA の協調単位を問題文や問題番号ではなく、型付き関係
`coll / perp / para / cong / cyclic / on_aline / eqangle3 / cc_tangent`
とする。各証明器は同じ関係を得意な表現へ落とし、結果を
`(関係型, 点列, 証明書)` として交換する。

本実験の仮説は、未接続の関係型をこの stalk に載せれば、既存エージェントの
能力を変更せずに、厳格な協調正答数が増える、というものである。

## 方法

- 対象: IMO-AG-30 の固定済み未解決13問。
- 補助構成: 非表示。問題の設定と目標だけを使用した。
- LLM: 不使用。
- 問題番号、既知解答、問題別ルール: 不使用。
- 受理条件: GCLCの証明、独立なJGEX多項式証明、型付き目標の一致を
  すべて満たすこと。

追加した一般変換は次の通り。

1. `cyclic(A,B,C,D)` を、円の中心を新設せず、二つの円周角の
   外積・内積恒等式へ変換した。
2. `on_aline` を直交基底間の直接相似として構成した。GCLCが証明器へ渡せない
   任意回転は、垂線と円の交点へ置換した。
3. `eqangle3` を接弦定理から円の中心を構成する経路へ変換した。
4. `cc_tangent` を相似中心と極線へ変換した。円円交点は完全四辺形による極線と
   直線円交点へ置換し、内分・外分の有限2枝を両方探索した。
5. 独立多項式側にも `cc_tangent` の半径条件と直交条件を追加した。

点名だけを変更した問題でGCLC命令列が不変になるテストを追加し、表層名や問題IDを
使う実装でないことも検査した。

## 結果

| 指標 | 拡張前 | 拡張後 |
|---|---:|---:|
| 未解決13問の翻訳可能数 | 6/13 | 13/13 |
| 翻訳不能 | 7 | 0 |
| 基準ソルバ単体 | 17/30 | 17/30 |
| 厳格な協調portfolio | 18/30 | 19/30 |
| 厳格な協調率 | 60.0% | 63.3% |
| 厳格な誤受理 | 0 | 0 |

新たに `2008_p1a` がGCLCと独立多項式証明の両方を通過した。`2008_p1b` は
GCLCが証明したが、独立側が180秒で時間切れのため厳格成功には数えていない。

`on_aline` 3問は「未接続」から「Wu法・Gröbner法が実行され内部時間切れ」へ移った。
`cc_tangent` も円円交点によるill-formedを除去でき、非退化枝では消去計算まで進んだが、
固定予算内の証明には至らなかった。

## 考察

結果は、関係型stalkの追加が翻訳被覆だけでなく、厳格な正答を1問増やしたことを示す。
一方、接続後に式が1000項から数千項へ膨張する例も確認した。したがって次の課題は
語彙追加ではなく、`on_aline` と `cc_tangent` を中間補題へ分割し、Newclidの局所導出と
GCLCの消去義務を小さく交換する前処理である。

これは完全なSheaf-ADMM自己組織化の再現ではない。現段階で実証できたのは、型付き
証明書を交換する協調カスケードにおいて、関係型の局所表現を追加すると既存エージェントの
厳格portfolioが改善する、という範囲である。

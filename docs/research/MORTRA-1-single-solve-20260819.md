# MORTRA-1 単問解答と全問題.tex監査

## 原理

公開画面の入力を二つのモードへ分けた。

- 1問入力: 問題文をLaTeX構文木、実行可能な数式、厳密計算、残差検査の順に処理し、問題文・解答・検証記録を返す。
- 2問入力: 二つの親問題から型付き構造を抽出し、融合問題・解答・検証記録を返す。

単問解答は外部LLMを使用しない。方程式、定積分、極限、微分はLaTeXからSymPyの式木へ直接変換する。それ以外は既存のMathOS型付き意味IRへ渡す。問題全体の検証が完了しない場合は、途中式が計算できても答えを公開しない。

## 実装

- 公開API: `api/solve.py`
- 公開UI: AまたはBの片方だけなら「問題を解く」、両方なら「融合問題を生成」へ自動切替
- 証明DAG: 1問入力では単一起点、2問入力では二起点を表示
- TeX反映: 既存解答を検出し、検証済みの新規解答だけを区切り付き追補として挿入
- 監査: 未解決問題へ推測解を補わず、JSONへ理由を記録

## 検証

- 単問API: 方程式、定積分、極限、微分、型付き幾何への接続、未検証時の棄却を含む7件に合格
- Python回帰: 15件合格
- 作図・有限状態・視覚中間表現: 31件合格
- Next.js本番ビルド: 合格
- TeX: 検証用upLaTeX変換で115ページのDVI生成に成功

PDF変換はローカルMiKTeXの日本語フォントマップ不足で停止した。TeX本文の構文エラーではない。

## 考察

最初の実装では、問題18の途中式だけが検証されたにもかかわらず全問正解として扱う偽陽性があった。合格条件を問題全体の `verification=verified` に限定し、追補対象から除外した。

85問中71問が未解決であり、現状を「任意の高校数学問題を解ける」とは評価できない。今回完成したのは、1問と2問を同じ公開画面から実行する経路、基本的な記号計算の厳密実行、誤答をTeXへ混入させない監査機構である。次の改善対象は、複数設問、幾何制約、整数条件、確率状態、証明問題を実行可能制約へ落とす層である。

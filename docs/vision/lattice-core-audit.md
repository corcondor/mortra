# Lattice Core 監査

## 固定値テストでは足りない

「FCC の配位数は 12」は既知の答えを埋め込んだだけで、未知の格子には何も言わない。
性質テストに置き換えた。

```
npx tsx scripts/verify-lattice.mts      固定値との一致   25/25
npx tsx scripts/lattice-properties.mts  性質テスト       93/93
```

## 性質テストの内容

```
dual(dual(L)) ≅ L                      双対の対合性
B → BU (U ∈ GL(3,ℤ)) で不変量が保たれる   基底変換の不変性
Aut(Λ) に単位元があり、積で閉じる           群であること
ルート系が鏡映で閉じ、−α もルート            ルート系であること
Cartan 整数がすべて整数
テータ係数 = 殻の点の数、定数項 = 1
2π 規約の違いが数値に現れる                黙って混ざらない
スケールでテータの指数が変わる               正規化を型で持つ必要がある
一次従属な基底で例外を出す                  黙って答えない
```

## 未見の格子

既知の値を持っていないものを混ぜて、同じ性質が成り立つか見る。

```
直方晶            [1,0,0] [0,1.7,0] [0,0,2.3]
六方（底面）       [1,0,0] [-0.5,√3/2,0] [0,0,1.633]
三斜晶            [1,0,0] [0.31,1.12,0] [0.17,0.23,1.41]
引き伸ばしたFCC    [0,0.5,0.9] [0.5,0,0.9] [0.5,0.5,0]
```

全部で 93/93。**ルート系にならない格子では、正しく棄権する**ことも確認した
（Cartan 整数が整数にならないので `type: null` を返す）。

## テスト自身のバグが2件見つかった

性質テストは、まず自分のテストの欠陥を出した。両方とも修正済み。

1. **探索範囲が基底に依存していた。** Gram 行列の成分から探索半径を決めていたので、
   基底を変換すると比較しているものが変わっていた。最小ノルムから決めるよう直した
2. **根の同一判定を文字列でやっていた。** √3/2 は計算経路が違うと末尾の桁が変わり、
   同じ点が別物と判定された。距離での比較に直した

固定値テストではどちらも見つからなかった。

## 規約は型として持つ

数値だけ持つと取り違えが黙って混ざる。

```
逆格子の規約          数学（2π なし） / 結晶学（2π あり）
ルート長の正規化       最小ノルム² = 2 が D₃ の標準形
テータの指数の規約      |x|² か |x|²/2 か
計量の規約
向きの規約
```

現状は数値で持っており、**型としては未実装**。`verify-lattice.mts` の
「2π 規約の違いが数値に現れる」はそれを検出できることの確認であって、
型で防いでいるわけではない。次の作業。

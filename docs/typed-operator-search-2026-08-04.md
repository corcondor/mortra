# 型付き演算 Atlas と親条件付き探索の改善（2026-08-04）

## 目的

親問題に未知の数学語・演算が含まれることを生成停止の理由にせず、問題テンプレートを追加せずに、
演算の型・法則・backend契約を増やして端点間の中間構造探索を進める。

## 今回追加した原始射

```text
IntegerPair -> GCDValue                 EuclideanMeet
IntegerPair -> LCMValue                 DivisibilityJoin
GCDValue x LCMValue -> Integer          GCDLCMProductLaw
Real -> Integer                         CeilingAdjunction / FloorAdjunction
RateQuantityPair -> Quantity            RationalScaleAction
```

各射は保存則と実行backendを持つ。問題ID、固定係数、正答、完成問題族は持たない。変数名・係数・
LaTeX表記を変えても同じ型付き経路へ落ちることをテストする。

## 探索速度

旧方式はworker 1回につき探索深さを1増やし、15分待機していた。新方式は1回のworker内で、20秒の
局所時間枠と状態予算の範囲で最大3段階を展開する。次回実行は進展あり1分、短期停滞2分、3回以上の
停滞5分。GitHub Actionsの最低再開周期も15分から5分へ短縮した。

UIはround/depthに加え、局所展開数、探索状態数、今回の進展量を表示する。計算中・次回待機・停滞を
区別し、画面が変わらない状態を「思考中」とは表示しない。

## 定量結果

Hendrycks MATH test splitの固定21問、LLM・Web検索・表層問題テンプレートなし、1問8秒で再測定した。

| 指標 | 変更前 | 変更後 |
|---|---:|---:|
| 全21問の回答 | 14 | 17 |
| 全21問の正答 | 12 | 16 |
| 数学IA近接15問の回答 | 10 | 13 |
| 数学IA近接15問の正答 | 9 | 13 |

標本は小さいため高校数学全体への汎化は主張しない。次の受理条件は、未見50問以上のfrozen split、
metamorphic test、回答precision、構造誤混同率である。

## 有限語彙と汎化

数学語彙と原始演算は有限に近いが、変数束縛、量化子、作用域、条件節、再帰的定義により構文木と
意味グラフの深さは無制限になり得る。そこで探索を次で制限する。

1. 選択された2問以上を固定端点にする。
2. 字句・構文解析から型付き意味IRを作る。
3. 型が一致する中間項・中間命題だけを列挙する。
4. 各射の保存則とbackend契約を検査する。
5. CAS・SMT・証明器で実行できた合成だけを問題へ昇格する。

この意味で、汎化対象は完成解法ではなく、有限の原始演算から作る型付き合成である。

## PrimitiveLawInducer

固定Atlasの深さだけを増やしても不足射は生まれないため、未登録の法則プログラムを帰納する閉ループを追加した。

```text
親の代数制約
-> 型付き多項式式文法を列挙
-> 既登録の和・差・積を除外
-> 意味シグネチャと消去多項式正規形で重複排除
-> 反復終結式による厳密消去
-> 全数値根対による反例検査
-> 左右それぞれの親摂動による不可欠性検査
-> 認証済み射を現在のenumeratorへ動的登録
-> 同じjob内で問題文・解答・証明証明書を生成
```

最初の実行文法は二つの一変数代数制約を対象とする。例えば `x^2-2=0` と `y^2-3=0` から、固定された
完成解法を選ばず `2xy`, `x^2y`, `xy^2` などを列挙する。`2xy` の値全体に対して厳密計算された
`P(z)=z^2-24` を返した。係数を `5,7` へ変えるmetamorphic testでは、同じ法則IDのまま答えが再計算される。

UI/APIは `induction_enumerated`, `induction_tested`, `induction_rejected`, `induced_laws` を公開する。
現段階は代数的制約用の第一backendであり、積分・整数・幾何の候補文法と検証器は同じインターフェースへ
追加する。対応外の型に証明なしの射を登録することはしない。

### 本番E2E

`sakumon-web.vercel.app/api/mathos-generate` へ答えなしの親 `u^2-5=0`, `v^2-7=0` を送信した。
job `1ff31399-81c9-45bb-b334-8c084e65cbf3` は次を完了した。

- 型付き式候補39件を生成、1件を実検証、反例棄却0件、新規射1件を認証。
- 動的射 `InducedAlgebraicLaw_b109c8c537` を現在の項列挙器へ登録。
- 型付き項332件、全親provenanceを持つ実行候補112件を列挙。
- `2 alpha beta` の値全体を根にもつ問題を生成。
- 厳密答え `P(z)=z^2-140` を計算し、数値反例検査・左右親摂動を通過。
- 検証済み問題1問を本番問題DBへ保存。

このE2EはLLM、Web検索、保存済み解答、問題ID分岐を使用していない。

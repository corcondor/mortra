### C. provisional predictive node

候補が複数、またはNEW可能性が残るhistoryについて、

```text
新stateと確定するまで何もしない
```

ことを禁止します。

そのhistoryを

```text
provisional node
```

として保持し、そのnodeから実際にactionを実行してtransition evidenceを集めてください。

provisional nodeはconfirmed stateではありません。

保存:

```text
history
existing candidate set
NEW flag
outgoing observed transitions
distinguishing certificates
evidence version
```

後から既存stateとの同一性が十分確認できればmerge。

既存stateのどれとも未来構造が整合しなくなればnew confirmed stateへ昇格。

誤って早期mergeしないでください。

### D. global E scanをやめ、discrimination treeを作る

現在の

```python
for representative in S:
    for suffix in E:
        compare(...)
```

をprimary classifierとして使わないでください。

既に獲得したDIFFERENT certificateを使って、

```text
Adaptive Discrimination Tree
```

を作成してください。

内部node:
```text
distinguishing suffix
```

branch:
```text
observed SAME / DIFFERENT / UNRESOLVED evidence
```

leaf:
```text
candidate representative set
```

としてください。

既知stateの識別時には、rootから必要なsuffixだけ実行してください。

全suffixを全representativeへ評価するのは監査用だけにしてください。

新しいsuffixが発見された場合も、全transitionを無条件に破棄して再計算しないでください。
影響するleafだけをrefineしてください。
